# 第20章 内置工具类型完全指南

TypeScript 内置了 20+ 个工具类型，用于在已有类型上做变换、提取和过滤。理解了它们的原理，你就掌握了类型编程最常用的"标准库"。本章按功能分组，逐一展示每个工具类型的用法、实现原理和常见场景。

## 属性修饰工具

这三个工具类型通过映射类型控制属性的可选性和只读性。

### Partial\<T\>

将所有属性变为可选：

```typescript
interface User {
  name: string;
  age: number;
  email: string;
}

type PartialUser = Partial<User>;
// { name?: string; age?: number; email?: string; }
```

**实现**：
```typescript
type Partial<T> = {
  [K in keyof T]?: T[K];
};
```

**场景**：更新操作的数据传输对象（DTO）：
```typescript
function updateUser(id: number, data: Partial<User>) {
  // data 可以只包含要更新的字段
}
```

### Required\<T\>

所有属性变为必选（移除可选性）：

```typescript
interface Config {
  url: string;
  method?: string;
  timeout?: number;
}

type FullConfig = Required<Config>;
// { url: string; method: string; timeout: number; }
```

**实现**：
```typescript
type Required<T> = {
  [K in keyof T]-?: T[K];
};
```

`-?` 是映射修饰符，移除 `?`。

### Readonly\<T\>

所有属性变为只读：

```typescript
interface Config {
  url: string;
  timeout: number;
}

const config: Readonly<Config> = { url: "/api", timeout: 5000 };
// config.url = "/other";  // ❌
```

**实现**：
```typescript
type Readonly<T> = {
  readonly [K in keyof T]: T[K];
};
```

**注意**：`Readonly<T>` 是浅层的——嵌套对象内部仍然可变。深层只读需要递归映射。

## 属性选取工具

### Pick\<T, K\>

从类型 `T` 中选择一组属性构造新类型：

```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

type PublicUser = Pick<User, "id" | "name">;
// { id: number; name: string; }
```

**实现**：
```typescript
type Pick<T, K extends keyof T> = {
  [P in K]: T[P];
};
```

### Omit\<T, K\>

从类型 `T` 中排除一组属性：

```typescript
type SafeUser = Omit<User, "password">;
// { id: number; name: string; email: string; }
```

**实现**：
```typescript
type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>;
```

`Omit` 是 `Pick` + `Exclude` 的组合——先排除键名，再选取剩余的。

## 键值构造工具

### Record\<K, V\>

构造一个对象类型，键类型为 `K`，值类型为 `V`：

```typescript
type PageInfo = Record<"home" | "about" | "contact", { title: string; url: string }>;
// {
//   home: { title: string; url: string; };
//   about: { title: string; url: string; };
//   contact: { title: string; url: string; };
// }
```

`K` 必须是 `string | number | symbol` 的子类型。

**实现**：
```typescript
type Record<K extends string | number | symbol, T> = {
  [P in K]: T;
};
```

**场景**：HTTP 状态码映射、枚举值 → 展示文案映射等。

## 联合类型筛选工具

### Exclude\<T, U\>

从联合类型 `T` 中排除可赋值给 `U` 的成员：

```typescript
type All = "a" | "b" | "c" | "d";
type Filtered = Exclude<All, "a" | "b">;  // "c" | "d"

type Mixed = string | number | (() => void);
type NonFunc = Exclude<Mixed, Function>;  // string | number
```

**实现**：
```typescript
type Exclude<T, U> = T extends U ? never : T;
```

利用分布式条件类型的特性——对联合的每个成员分别判断，满足的转为 `never`（被消除），不满足的保留。

### Extract\<T, U\>

从联合类型 `T` 中提取可赋值给 `U` 的成员（与 `Exclude` 相反）：

```typescript
type Mixed = string | number | (() => void);
type Funcs = Extract<Mixed, Function>;  // () => void
```

**实现**：
```typescript
type Extract<T, U> = T extends U ? T : never;
```

### NonNullable\<T\>

从类型 `T` 中排除 `null` 和 `undefined`：

```typescript
type T0 = NonNullable<string | number | undefined>;  // string | number
type T1 = NonNullable<string[] | null | undefined>;   // string[]
```

**实现**：
```typescript
type NonNullable<T> = T & {};  // 或 T extends null | undefined ? never : T
```

## 函数类型工具

这些工具类型使用 `infer` 从函数类型中提取子类型。

### ReturnType\<T\>

提取函数类型的返回值类型：

```typescript
declare function createUser(): { id: number; name: string };
type User = ReturnType<typeof createUser>;  // { id: number; name: string; }

// 最常用的模式
type FetchResult = ReturnType<typeof fetch>;  // Promise<Response>
```

**实现**：
```typescript
type ReturnType<T extends (...args: any) => any> = 
  T extends (...args: any) => infer R ? R : any;
```

`any` 和 `never` 作为类型参数时分别返回 `any` 和 `never`。

### Parameters\<T\>

提取函数类型的参数列表类型（以元组形式）：

```typescript
declare function createUser(name: string, age: number, admin?: boolean): void;
type CreateUserArgs = Parameters<typeof createUser>;
// [name: string, age: number, admin?: boolean]
```

**实现**：
```typescript
type Parameters<T extends (...args: any) => any> = 
  T extends (...args: infer P) => any ? P : never;
```

**场景**：复用已有函数的参数类型：
```typescript
// 如果有另一个函数接受同样的参数
function createUsers(...args: CreateUserArgs) {
  return createUser(...args);
}
```

### ConstructorParameters\<T\>

提取构造函数类型的参数元组：

```typescript
class User {
  constructor(public name: string, public age: number) {}
}

type UserCtorArgs = ConstructorParameters<typeof User>;
// [name: string, age: number]
```

**实现**：
```typescript
type ConstructorParameters<T extends abstract new (...args: any) => any> = 
  T extends abstract new (...args: infer P) => any ? P : never;
```

### InstanceType\<T\>

提取构造函数类型的实例类型：

```typescript
class User {
  constructor(public name: string, public age: number) {}
}

type UserInstance = InstanceType<typeof User>;  // User
```

**实现**：
```typescript
type InstanceType<T extends abstract new (...args: any) => any> = 
  T extends abstract new (...args: any) => infer R ? R : any;
```

### ThisParameterType\<T\>

提取函数类型的 `this` 参数类型：

```typescript
function greet(this: { name: string }) {
  console.log(`Hello, ${this.name}`);
}

type ThisCtx = ThisParameterType<typeof greet>;  // { name: string }
```

如果没有 `this` 参数，返回 `unknown`。

**实现**：
```typescript
type ThisParameterType<T> = 
  T extends (this: infer U, ...args: never) => any ? U : unknown;
```

### OmitThisParameter\<T\>

移除函数类型中的 `this` 参数：

```typescript
function greet(this: { name: string }, greeting: string): string {
  return `${greeting}, ${this.name}`;
}

type PlainGreet = OmitThisParameter<typeof greet>;
// (greeting: string) => string
```

## Promise 工具

### Awaited\<T\>

递归解包 Promise 链，获取最终的值类型：

```typescript
type A = Awaited<Promise<string>>;           // string
type B = Awaited<Promise<Promise<number>>>;  // number（递归解包）
type C = Awaited<boolean | Promise<number>>; // boolean | number
```

如果 `T` 不是 Promise-like 类型，原样返回。

## NoInfer\<T\>（TS 5.4+）

阻止 TypeScript 从某个位置推导泛型参数：

```typescript
function get<T>(value: T, fallback: NoInfer<T>): T {
  return value ?? fallback;
}

// 没有 NoInfer：TypeScript 会从两个参数推导 T，可能导致类型过宽
// 有了 NoInfer：fallback 只用于检查，不参与推导
```

## 字符串操作工具

这四个内置类型通过编译器 intrinsic 实现，对应 JavaScript 运行时字符串方法：

| 工具类型 | 效果 |
|---------|------|
| `Uppercase<S>` | 全部大写 |
| `Lowercase<S>` | 全部小写 |
| `Capitalize<S>` | 首字母大写 |
| `Uncapitalize<S>` | 首字母小写 |

```typescript
type T1 = Uppercase<"hello">;      // "HELLO"
type T2 = Lowercase<"HELLO">;      // "hello"
type T3 = Capitalize<"hello">;     // "Hello"
type T4 = Uncapitalize<"Hello">;   // "hello"
```

## ThisType\<T\>

这个特殊的工具类型本身是空接口——它不产生任何类型变换，而是作为**上下文标记**，告诉 TypeScript 某个对象字面量中的 `this` 应该是什么类型：

```typescript
type ObjectDescriptor<D, M> = {
  data?: D;
  methods?: M & ThisType<D & M>;  // methods 中的 this 是 D & M
};

function makeObject<D, M>(desc: ObjectDescriptor<D, M>): D & M {
  const data = desc.data || {};
  const methods = desc.methods || {};
  return { ...data, ...methods } as D & M;
}

const obj = makeObject({
  data: { x: 0, y: 0 },
  methods: {
    moveBy(dx: number, dy: number) {
      // this 的类型被推断为 { x: number; y: number; moveBy: ...; }
      this.x += dx;
      this.y += dy;
    },
  },
});
```

需要开启 `noImplicitThis` 才能生效。

## 工具类型速查表

| 工具类型 | 输入 | 输出 | 实现方式 |
|---------|------|------|---------|
| `Partial<T>` | 对象类型 | 全部可选 | 映射类型 + `?` |
| `Required<T>` | 对象类型 | 全部必选 | 映射类型 + `-?` |
| `Readonly<T>` | 对象类型 | 全部只读 | 映射类型 + `readonly` |
| `Pick<T, K>` | 对象类型 + 键联合 | 选取属性 | 映射类型 + 约束 |
| `Omit<T, K>` | 对象类型 + 键联合 | 排除属性 | Pick + Exclude |
| `Record<K, V>` | 键联合 + 值类型 | 键值映射 | 映射类型 |
| `Exclude<T, U>` | 联合类型 | 排除成员 | 分布式条件 + `never` |
| `Extract<T, U>` | 联合类型 | 提取成员 | 分布式条件 |
| `NonNullable<T>` | 任何类型 | 去 null/undefined | 分布式条件 或 `T & {}` |
| `ReturnType<T>` | 函数类型 | 返回值类型 | `infer R` |
| `Parameters<T>` | 函数类型 | 参数元组 | `infer P` |
| `ConstructorParameters<T>` | 构造函数类型 | 构造参数元组 | `infer P` |
| `InstanceType<T>` | 构造函数类型 | 实例类型 | `infer R` |
| `ThisParameterType<T>` | 函数类型 | this 类型 | `infer U` |
| `OmitThisParameter<T>` | 函数类型 | 去 this 的函数 | `infer` 重组 |
| `Awaited<T>` | Promise-like | 解包值类型 | 条件类型 + 递归 |
| `NoInfer<T>` | 任何类型 | 阻止推导 | 编译器标记 |
| `Uppercase<S>` | 字符串 | 大写 | intrinsic |
| `Lowercase<S>` | 字符串 | 小写 | intrinsic |
| `Capitalize<S>` | 字符串 | 首字母大写 | intrinsic |
| `Uncapitalize<S>` | 字符串 | 首字母小写 | intrinsic |
| `ThisType<T>` | 对象类型 | 空接口（标记） | 编译器标记 |

## 本章小结

- 工具类型按功能可分为：**属性修饰**、**属性选取**、**键值构造**、**联合类型筛选**、**函数类型提取**、**Promise 解包**、**字符串操作**
- 每个工具类型的实现都是映射类型、条件类型、`infer` 和分布式特性之一或组合
- `Partial`、`Required`、`Readonly` 用映射修饰符实现
- `Exclude`、`Extract`、`NonNullable` 用分布式条件类型实现
- `ReturnType`、`Parameters` 系列用 `infer` 实现
- `ThisType<T>` 是特殊的上下文标记（不产生类型变换）
