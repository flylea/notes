# TypeScript 入门到进阶教程

本教程从零开始，系统讲解 TypeScript 的全部核心知识，从基础类型标注到高级类型编程，再到工程实践与面试技巧。适合 TypeScript 初学者和希望系统提升的中级开发者。

## 教程特点

- **系统全面**：30 章内容，覆盖从基础标注到类型编程、从 React 到 Node.js 的全链路知识
- **循序渐进**：分为基础篇、类型进阶篇、类型编程篇、工程实践篇，由浅入深
- **实战导向**：每个概念都配有可运行的代码示例，注重实际开发场景
- **紧跟标准**：基于 TypeScript 5.x/6.0 官方文档（2026 年最新版）编写
