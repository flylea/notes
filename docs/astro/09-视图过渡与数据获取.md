## 第九章：视图过渡动画与数据获取

### 9.1 视图过渡动画概述

Astro 的视图过渡动画让你无需 React/Vue 等框架即可实现 SPA 般的页面切换效果。

#### 启用视图过渡

```bash
npx astro add view-transitions
```

或在布局中手动导入：

```astro
---
// src/layouts/BaseLayout.astro
import { ViewTransitions } from 'astro:transitions';
---

<!doctype html>
<html lang="zh-CN">
  <head>
    <ViewTransitions />
  </head>
  <body>
    <slot />
  </body>
</html>
```

### 9.2 页面过渡动画

#### 内置动画

```astro
<!-- 默认淡入淡出 -->
<h1 transition:animate="fade">标题</h1>

<!-- 滑动效果 -->
<section transition:animate="slide">内容</section>

<!-- 无动画 -->
<footer transition:animate="none">页脚</footer>
```

#### 前进/后退不同动画

```astro
<div
  transition:animate="slide"
  transition:animate.back="fade"
>
  内容

</div>
```

#### 保留元素

```astro
<header transition:name="header">
  <nav>导航栏（保持不变）</nav>
</header>
```

### 9.3 自定义过渡动画

```css
/* src/styles/transitions.css */
::view-transition-old(root) {
  animation: 0.4s ease-out both fade-out;
}
::view-transition-new(root) {
  animation: 0.4s ease-in both fade-in;
}

@keyframes fade-out {
  from { opacity: 1; }
  to { opacity: 0; }
}
@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

### 9.4 数据获取方式

#### 构建时获取（默认）

```astro
---
// 在构建时执行一次
const posts = await fetch('https://api.example.com/posts')
  .then(r => r.json());

const products = await fetch('https://api.example.com/products')
  .then(r => r.json());
---

<ul>
  {posts.map(p => <li>{p.title}</li>)}
</ul>
```

#### 请求时获取（SSR）

```astro
---
export const prerender = false;

const { slug } = Astro.params;
const post = await fetch(`https://api.example.com/posts/${slug}`)
  .then(r => r.json());

if (!post) {
  return Astro.redirect('/404');
}
---

<article>
  <h1>{post.title}</h1>
  <div set:html={post.content} />
</article>
```

#### 带认证的数据获取

```astro
---
const data = await fetch('https://api.example.com/admin/stats', {
  headers: {
    'Authorization': `Bearer ${import.meta.env.API_SECRET}`,
    'Content-Type': 'application/json',
  },
}).then(r => r.json());
---
```

### 9.5 数据获取最佳实践

```astro
---
// ✅ 并行获取多个数据源
const [posts, products, config] = await Promise.all([
  fetch('https://api.example.com/posts').then(r => r.json()),
  fetch('https://api.example.com/products').then(r => r.json()),
  fetch('https://api.example.com/config').then(r => r.json()),
]);

// ✅ 错误处理
let data = null;
let error = null;

try {
  data = await fetch('https://api.example.com/data').then(r => {
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return r.json();
  });
} catch (e) {
  error = e.message;
}
---

{error ? <p class="error">加载失败: {error}</p> : <DataView data={data} />}
```

### 9.6 环境变量

```env
# .env
PUBLIC_SITE_URL=https://example.com
PUBLIC_ANALYTICS_ID=G-XXXXXXXXXX
SECRET_API_KEY=sk-xxxxxxxxxxxxxx
DATABASE_URL=libsql://...
```

```astro
---
// 公有环境变量（客户端可用）
const siteUrl = import.meta.env.PUBLIC_SITE_URL;
const analyticsId = import.meta.env.PUBLIC_ANALYTICS_ID;

// 私有环境变量（仅服务端可用）
const apiKey = import.meta.env.SECRET_API_KEY;
const dbUrl = import.meta.env.DATABASE_URL;
---
```

```ts
// src/env.d.ts — 类型安全的环境变量
/// <reference types="astro/client" />
interface ImportMetaEnv {
  readonly PUBLIC_SITE_URL: string;
  readonly PUBLIC_ANALYTICS_ID: string;
  readonly SECRET_API_KEY: string;
  readonly DATABASE_URL: string;
}
interface ImportMeta { readonly env: ImportMetaEnv; }
```

### 9.7 Astro DB 快速入门

```bash
npx astro add db
```

```ts
// db/config.ts
import { defineDb, defineTable, column } from 'astro:db';

const Comment = defineTable({
  columns: {
    id: column.number({ primaryKey: true }),
    author: column.text(),
    body: column.text(),
    postSlug: column.text(),
    createdAt: column.date({ default: new Date() }),
  },
});

export default defineDb({ tables: { Comment } });
```

```astro
---
import { db, Comment, eq, desc } from 'astro:db';

// 查询评论
const comments = await db
  .select()
  .from(Comment)
  .where(eq(Comment.postSlug, Astro.params.slug ?? ''))
  .orderBy(desc(Comment.createdAt));
---

<h2>评论 ({comments.length})</h2>
{comments.map(c => (
  <div>
    <strong>{c.author}</strong>
    <p>{c.body}</p>
    <time>{c.createdAt.toLocaleDateString('zh-CN')}</time>
  </div>
))}
```

### 9.8 国际化（i18n）路由

```js
// astro.config.mjs
export default defineConfig({
  i18n: {
    defaultLocale: 'zh-CN',
    locales: ['zh-CN', 'en', 'ja'],
    routing: {
      prefixDefaultLocale: false, // / 直接访问中文版
    },
  },
});
```

```
src/pages/
├── index.astro       → /         (中文)
├── en/
│   └── index.astro   → /en/      (英文)
└── ja/
    └── index.astro   → /ja/      (日文)
```

```astro
---
import { getRelativeLocaleUrl } from 'astro:i18n';

const enUrl = getRelativeLocaleUrl('en', Astro.url.pathname);
---

<a href={enUrl}>English</a>
```

### 本章小结

- 视图过渡动画无需前端框架，内置 fade/slide 效果
- 数据可在构建时获取（静态）或请求时获取（SSR）
- 环境变量以 `PUBLIC_` 前缀区分客户端/服务端
- Astro DB 基于 Drizzle ORM + libSQL，开箱即用
- i18n 路由从 v4.0 开始内置支持
