## 第五章：内容集合

### 5.1 什么是内容集合？

内容集合是 Astro 管理结构化内容的核心 API。无论是博客文章、产品描述、角色档案还是其他结构化内容，内容集合提供了统一的管理方式，包括：

- **类型安全**：基于 Zod Schema 的自动验证和 TypeScript 类型推断
- **自动验证**：构建时自动校验所有条目的 frontmatter
- **编辑器智能提示**：编写内容时获得自动补全和错误提示
- **灵活查询**：`getCollection()`、`getEntry()` 等 API 轻松获取和过滤内容
- **两种模式**：构建时集合（静态）和实时集合（SSR）

### 5.2 集合目录结构

```
src/content/
├── config.ts          ← 配置文件和 Schema 定义
├── blog/              ← "blog" 集合（content 类型）
│   ├── post-1.md
│   ├── post-2.md
│   └── draft-post.md
└── authors/           ← "authors" 集合（data 类型）
    ├── alice.json
    └── bob.yaml
```

### 5.3 定义集合

在 `src/content/config.ts`（Astro v6 中也可使用 `src/content.config.ts`）中定义：

```ts
// src/content/config.ts
import { defineCollection, z } from 'astro:content';

// 构建时集合（content 类型：.mdx / .md 文件）
const blogCollection = defineCollection({
  loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/blog' }),
  schema: z.object({
    title: z.string(),
    description: z.string(),
    publishDate: z.coerce.date(),
    updatedDate: z.coerce.date().optional(),
    tags: z.array(z.string()).default([]),
    image: z.string().optional(),
    draft: z.boolean().default(false),
    author: z.string().default('Anonymous'),
  }),
});

// 构建时集合（data 类型：.json / .yaml 文件）
const authorsCollection = defineCollection({
  loader: glob({ pattern: '**/*.{json,yaml}', base: './src/content/authors' }),
  schema: z.object({
    name: z.string(),
    email: z.string().email(),
    avatar: z.string().url(),
    bio: z.string().optional(),
    website: z.string().url().optional(),
  }),
});

// 实时集合（每次请求时动态获取）
const productsCollection = defineCollection({
  loader: async () => {
    // 从外部 API 加载数据
    const response = await fetch('https://api.example.com/products');
    const products = await response.json();
    return products.map(p => ({
      id: p.slug,
      ...p,
    }));
  },
  schema: z.object({
    name: z.string(),
    price: z.number(),
    category: z.string(),
    inStock: z.boolean(),
  }),
});

export const collections = {
  blog: blogCollection,
  authors: authorsCollection,
  products: productsCollection,
};
```

### 5.4 使用 Zod Schema 定义字段

Astro 内容集合使用 **Zod** 进行 schema 验证。以下是常用 Zod 类型：

```ts
import { z } from 'astro:content';

const schema = z.object({
  // 字符串类型
  title: z.string(),
  slug: z.string().min(1).max(100),
  email: z.string().email(),
  url: z.string().url(),

  // 数字类型
  price: z.number(),
  rating: z.number().min(0).max(5),
  views: z.number().int().positive(),

  // 日期类型
  publishDate: z.date(),       // 需要 Date 格式
  publishDate: z.coerce.date(), // 自动转换字符串为 Date

  // 布尔类型
  featured: z.boolean(),
  draft: z.boolean().default(false),

  // 数组类型
  tags: z.array(z.string()),
  colors: z.array(z.enum(['red', 'green', 'blue'])),

  // 可选字段
  image: z.string().optional(),
  description: z.string().default(''),

  // 枚举类型
  status: z.enum(['published', 'draft', 'archived']),

  // 联合类型
  category: z.union([z.literal('tech'), z.literal('life'), z.string()]),

  // 嵌套对象
  author: z.object({
    name: z.string(),
    email: z.string().email(),
  }),

  // 任何有效值（跳过验证）
  metadata: z.any(),
});
```

### 5.5 加载器（Loader）

Astro v6.x 引入了加载器 API，定义了"如何获取和查找集合条目"。

#### `glob()` 加载器（构建时）

```ts
const blog = defineCollection({
  loader: glob({
    pattern: '**/*.{md,mdx}',      // 匹配的文件模式
    base: './src/content/blog',     // 搜索的根目录
    // generateId: ({ data }) => data.slug  // 自定义 ID 生成
  }),
  schema: z.object({
    title: z.string(),
  }),
});
```

#### `file()` 加载器（单个文件）

```ts
const siteConfig = defineCollection({
  loader: file('./src/content/site-config.json', {
    parser: 'json',   // 自动解析 JSON
  }),
  schema: z.object({
    siteName: z.string(),
    description: z.string(),
  }),
});
```

#### 自定义构建时加载器

```ts
const products = defineCollection({
  loader: async () => {
    const data = await fetchProductsFromCMS();
    return data.map(item => ({
      id: item.slug,
      title: item.name,
      ...item,
    }));
  },
  schema: z.object({
    title: z.string(),
    price: z.number(),
  }),
});
```

### 5.6 查询集合

#### `getCollection()`

获取集合中的所有条目：

```astro
---
import { getCollection } from 'astro:content';

// 获取所有博客文章
const allPosts = await getCollection('blog');

// 带过滤条件
const publishedPosts = await getCollection('blog', ({ data }) => {
  return data.draft !== true;
});

// 按日期排序
const sortedPosts = publishedPosts.sort(
  (a, b) => b.data.publishDate.getTime() - a.data.publishDate.getTime()
);

// 按标签过滤
const techPosts = await getCollection('blog', ({ data }) => {
  return data.tags.includes('tech');
});
---

<ul>
  {sortedPosts.map(post => (
    <li>
      <a href={`/blog/${post.slug}`}>
        {post.data.title}
      </a>
      <span>{post.data.publishDate.toLocaleDateString('zh-CN')}</span>
    </li>
  ))}
</ul>
```

#### `getEntry()`

获取单个条目：

```astro
---
import { getEntry } from 'astro:content';

// 按 slug 获取
const post = await getEntry('blog', 'hello-world');

// 按完整路径获取
const author = await getEntry('authors', 'alice');
---

<h1>{post.data.title}</h1>
```

#### `getEntries()`

获取多个条目（按 slug 数组）：

```ts
const featuredPosts = await getEntries('blog', [
  'post-1',
  'post-2',
  'post-3',
]);
```

### 5.7 渲染内容

内容集合条目可以渲染为 HTML：

```astro
---
// src/pages/blog/[...slug].astro
import { getCollection } from 'astro:content';

export async function getStaticPaths() {
  const posts = await getCollection('blog');
  return posts.map(post => ({
    params: { slug: post.slug },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content } = await post.render();
---

<article>
  <h1>{post.data.title}</h1>
  <time>{post.data.publishDate.toLocaleDateString('zh-CN')}</time>

  <!-- Content 组件渲染 Markdown 正文 -->
  <Content />
</article>
```

### 5.9 集合引用（References）

在集合之间建立关联：

```ts
// src/content/config.ts
const blog = defineCollection({
  schema: z.object({
    title: z.string(),
    // 引用 authors 集合中的条目
    author: z.reference('authors'),
    // 引用其他博客文章（关联文章）
    relatedPosts: z.array(z.reference('blog')).optional(),
  }),
});
```

使用时：

```astro
---
import { getEntry } from 'astro:content';

const post = await getEntry('blog', 'hello-world');
// post.data.author 的类型是 { id: string; collection: 'authors'; data: AuthorData }
// 可以直接获取关联数据
const author = await getEntry(post.data.author);
---
```

### 5.11 构建时集合 vs 实时集合对比

| 特性 | 构建时集合 | 实时集合 |
|---|---|---|
| 定义函数 | `defineCollection()` | `defineLiveCollection()` |
| 配置文件 | `src/content/config.ts` | `src/live.config.ts` |
| 查询函数 | `getCollection()` / `getEntry()` | `getLiveCollection()` / `getLiveEntry()` |
| 数据获取时机 | 构建时 | 每次请求时 |
| 适用场景 | 博客文章、产品列表 | 用户评论、实时数据 |
| 路由生成 | `getStaticPaths()` | 按需渲染（`prerender = false`） |

### 5.12 路由生成完整示例

```astro
---
// src/pages/blog/[...slug].astro
import { getCollection } from 'astro:content';
import BaseLayout from '../../layouts/BaseLayout.astro';

// 静态生成所有文章页面
export async function getStaticPaths() {
  const posts = await getCollection('blog', ({ data }) => {
    return data.draft !== true;
  });

  return posts.map(post => ({
    params: { slug: post.slug },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content, headings } = await post.render();
---

<BaseLayout title={post.data.title} description={post.data.description}>
  <article class="blog-post">
    <!-- 文章头 -->
    <header>
      <h1>{post.data.title}</h1>
      <div class="meta">
        <time datetime={post.data.publishDate.toISOString()}>
          {post.data.publishDate.toLocaleDateString('zh-CN')}
        </time>
        <span class="tags">
          {post.data.tags.map(tag => (
            <a href={`/tags/${tag}`} class="tag">{tag}</a>
          ))}
        </span>
      </div>
    </header>

    <!-- 目录（从标题自动生成） -->
    {headings.length > 0 && (
      <nav class="toc">
        <h2>目录</h2>
        <ul>
          {headings
            .filter(h => h.depth <= 3)
            .map(h => (
              <li style={`padding-left: ${(h.depth - 1) * 1}rem`}>
                <a href={`#${h.slug}`}>{h.text}</a>
              </li>
            ))}
        </ul>
      </nav>
    )}

    <!-- Markdown 内容 -->
    <div class="content">
      <Content />
    </div>
  </article>
</BaseLayout>
```

### 5.13 集合 API 速查表

| API | 说明 |
|---|---|
| `defineCollection(opts)` | 定义集合 |
| `getCollection(name, filter?)` | 获取集合中的所有条目 |
| `getEntry(name, slug)` | 获取单个条目 |
| `getEntries(name, slugs[])` | 批量获取条目 |
| `entry.render()` | 渲染 Markdown/MDX 内容 |
| `entry.slug` | 条目的 URL slug |
| `entry.id` | 条目的唯一标识 |
| `entry.data` | 条目的 frontmatter 数据（经过 Zod 验证） |
| `entry.body` | 条目的原始内容体 |
| `z.reference(collection)` | 创建跨集合引用 |
| `render()` 返回的 `Content` 组件 | 渲染正文的 Astro 组件 |
| `render()` 返回的 `headings` | 从 Markdown 提取的标题列表 |

### 本章小结

- **内容集合**是 Astro 管理结构化内容的核心方式
- 使用 **Zod Schema** 定义和验证字段类型
- **`glob()` 加载器**从本地文件读取，**自定义加载器**从外部 API 加载
- `getCollection()`、`getEntry()` 提供类型安全的查询
- `render()` + `<Content />` 组件渲染 Markdown 正文
- **引用（references）** 实现集合之间的关联
- 支持构建时和实时两种模式
