## 第六章：图像与资源管理

### 6.1 `astro:assets` 简介

Astro 提供了内建的图像优化能力，通过 `astro:assets` 模块提供三个核心组件：

| 组件 | 用途 |
|---|---|
| `<Image />` | 单张图片优化（生成 `<img>` 标签） |
| `<Picture />` | 响应式图片（生成 `<picture>` 标签，多格式多尺寸） |
| `<Background />` | 背景图优化（内联背景图） |

### 6.2 本地图像处理

#### 导入本地图片

```astro
---
import { Image } from 'astro:assets';
import heroImage from '../assets/hero.jpg';  // 导入时自动获取元数据

// 图片导入后可以访问宽高、格式等信息
console.log(heroImage.width);   // 原始宽度
console.log(heroImage.height);  // 原始高度
console.log(heroImage.format);  // 'jpg'
---

<!-- 自动优化：压缩、转换格式、调整尺寸 -->
<Image
  src={heroImage}
  alt="网站主图"
  width={800}
  height={400}
/>
```

#### 图片存放位置

```
src/
├── assets/          ← 推荐：需要 Astro 优化的图片
│   └── hero.jpg
├── images/          ← 也可用此目录
│   └── logo.png
└── pages/
    └── index.astro

public/              ← 不需要优化的静态图片
    └── favicon.ico
```

> 在 `public/` 中的图片直接当静态文件用，不被 Astro 优化。

### 6.3 `<Image />` 组件

#### 基本用法

```astro
---
import { Image } from 'astro:assets';
import photo from '../assets/photo.jpg';
---

<Image src={photo} alt="照片描述" />

<!-- 指定宽度（自动计算高度保持比例） -->
<Image src={photo} alt="照片" width={600} />

<!-- 同时指定宽高 -->
<Image src={photo} alt="照片" width={600} height={400} />

<!-- 指定输出格式 -->
<Image src={photo} alt="照片" format="webp" />

<!-- 指定图片质量 -->
<Image src={photo} alt="照片" quality={80} />

<!-- 组合使用 -->
<Image
  src={photo}
  alt="优化的照片"
  width={800}
  height={600}
  format="avif"         <!-- 输出 AVIF 格式 -->
  quality={85}          <!-- 质量 85% -->
  loading="lazy"        <!-- 懒加载 -->
  decoding="async"      <!-- 异步解码 -->
/>
```

#### 支持的输出格式

| 格式 | 特点 | 适用场景 |
|---|---|---|
| `webp` | 体积小，质量好 | 大多数场景（推荐） |
| `avif` | 体积最小，质量最优 | 最新浏览器 |
| `png` | 无损，支持透明 | 需要透明的图片 |
| `jpeg` | 通用格式 | 照片、复杂图片 |

#### 远程图片

```astro
---
import { Image } from 'astro:assets';
---

<!-- 远程图片：必须指定 width 和 height -->
<Image
  src="https://example.com/photo.jpg"
  alt="远程图片"
  width={800}
  height={600}
/>

<!-- 或在配置中允许的远程域名列表 -->
```

```js
// astro.config.mjs
export default defineConfig({
  image: {
    domains: ['example.com', 'cdn.myapp.com'],
    remotePatterns: [
      { protocol: 'https', hostname: '**.example.com' },
    ],
  },
});
```

### 6.4 `<Picture />` 组件

用于响应式图片，自动生成多种格式和尺寸：

```astro
---
import { Picture } from 'astro:assets';
import hero from '../assets/hero.jpg';
---

<!-- 多格式 + 多尺寸 = 最佳性能和兼容性 -->
<Picture
  src={hero}
  formats={['avif', 'webp']}    <!-- 自动生成 AVIF 和 WebP 版本 -->
  widths={[400, 800, 1200]}     <!-- 生成 3 个尺寸 -->
  sizes="(max-width: 800px) 100vw, 50vw"
  alt="响应式主图"
/>

<!-- 生成效果：
<picture>
  <source srcset="hero-400.avif 400w, hero-800.avif 800w, hero-1200.avif 1200w"
          sizes="..." type="image/avif" />
  <source srcset="hero-400.webp 400w, ..."
          sizes="..." type="image/webp" />
  <img src="hero.jpg" alt="响应式主图" ... />
</picture>
-->
```

### 6.5 使用 `getImage()` 函数

在组件脚本中编程式生成图像：

```astro
---
import { getImage } from 'astro:assets';
import background from '../assets/bg.jpg';

// 在脚本中生成优化后的图像元数据
const optimizedBg = await getImage({
  src: background,
  width: 1200,
  format: 'webp',
});
---

<div style={`background-image: url(${optimizedBg.src})`}>
  内容区域
</div>
```

### 6.6 图像服务

Astro 支持不同的图像处理服务：

```js
// astro.config.mjs
export default defineConfig({
  image: {
    // 默认：使用 Sharp（Node.js 本地处理）
    service: {
      entrypoint: 'astro/assets/services/sharp',
    },

    // 使用 Cloudflare 图像服务（部署到 Cloudflare 时）
    // service: {
    //   entrypoint: 'astro/assets/services/noop',
    // },
  },
});
```

### 6.7 静态资源

#### public/ 目录

`public/` 目录下的文件不经过 Astro 处理，直接复制到构建输出：

```
public/
├── favicon.ico
├── robots.txt
├── fonts/
│   └── inter.woff2
└── downloads/
    └── resume.pdf
```

引用方式：使用根路径 `/`

```astro
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
<img src="/images/unoptimized-photo.jpg" alt="不优化的图片" />
<a href="/downloads/resume.pdf">下载简历</a>
```

#### src/assets/ vs public/ 选择指南

| 场景 | 使用位置 |
|---|---|
| 需要 Astro 优化的图片 | `src/assets/` + `astro:assets` |
| 网站图标、robots.txt | `public/` |
| 下载文件 | `public/` |
| 不处理的静态图片 | `public/` |
| 字体文件 | `public/fonts/` 或 `src/fonts/` |

### 6.8 导入资源

Astro 支持导入多种文件类型：

```astro
---
// 图片来源
import hero from '../assets/hero.jpg';

---

<a href={pdfUrl}>下载文档</a>
```

### 6.9 字体管理

Astro v6.x 提供了实验性的 Font API：

```js
// astro.config.mjs
export default defineConfig({
  experimental: {
    fonts: [
      {
        cssVariableName: '--font-heading',
        provider: 'fontsource',
        name: 'Inter',
        weights: ['600', '700', '800'],
        styles: ['normal'],
      },
      {
        cssVariableName: '--font-body',
        provider: 'fontsource',
        name: 'Noto Sans SC',
        weights: ['400', '500'],
      },
    ],
  },
});
```

传统方式：使用 Fontsource 或 Google Fonts：

```bash
# 安装 Fontsource 字体
npm install @fontsource/inter @fontsource/noto-sans-sc
```

```css
/* 全局 CSS */
@import '@fontsource/inter/400.css';
@import '@fontsource/inter/600.css';
@import '@fontsource/inter/700.css';

body {
  font-family: 'Inter', system-ui, sans-serif;
}
```

### 6.11 完整示例：带图片的文章页面

```astro
---
import { Image, getImage } from 'astro:assets';
import BaseLayout from '../layouts/BaseLayout.astro';
import { getEntry } from 'astro:content';
import coverFallback from '../assets/cover-default.jpg';

const post = await getEntry('blog', 'hello-world');
const { Content } = await post.render();

// 封面图（如果存在）
let coverImage;
if (post.data.image) {
  try {
    const importedImg = await import(`../assets/${post.data.image}`);
    coverImage = importedImg.default;
  } catch {
    coverImage = coverFallback;
  }
}

// 生成优化后的社交分享图
const ogImage = coverImage ? await getImage({
  src: coverImage,
  width: 1200,
  height: 630,
  format: 'jpeg',
}) : null;
---

<BaseLayout
  title={post.data.title}
  description={post.data.description}
  image={ogImage?.src}
>
  <article class="post">
    <header class="post-header">
      <h1>{post.data.title}</h1>
      <time>{post.data.publishDate.toLocaleDateString('zh-CN')}</time>
    </header>

    {coverImage && (
      <Image
        src={coverImage}
        alt={post.data.title}
        width={800}
        height={400}
        format="webp"
        class="cover-image"
        loading="eager"
      />
    )}

    <div class="post-content">
      <Content />
    </div>
  </article>
</BaseLayout>
```

### 本章小结

- **`<Image />`** 组件自动优化单张图片（压缩、格式转换、尺寸调整）
- **`<Picture />`** 组件提供响应式图片（多格式 + 多尺寸）
- **`getImage()`** 函数在脚本中编程式生成图像
- **`public/`** 目录存放不需要处理的静态文件
- **字体**通过 Fontsource 或实验性 Font API 管理
- 图片优化在**构建时**完成，生产环境零性能开销
