## 第十章：集成、部署与进阶实践

### 10.1 Astro 集成系统

`npx astro add` 是添加集成的统一入口，自动安装依赖、配置 `astro.config.mjs`。

#### 官方核心集成

| React | `npx astro add react` | React 组件 |
| Vue | `npx astro add vue` | Vue 组件 |
| Svelte | `npx astro add svelte` | Svelte 组件 |
| SolidJS | `npx astro add solid` | SolidJS 组件 |
| Preact | `npx astro add preact` | Preact 组件 |
| Alpine.js | `npx astro add alpinejs` | 轻量交互 |

### 10.2 部署平台

#### 静态部署流程

```bash
npm run build        # 生成 dist/ 目录
# 将 dist/ 上传到任意静态托管平台即可
```

#### Netlify

```bash
npx astro add netlify
```

```toml
# netlify.toml
[build]
  command = "npm run build"
  publish = "dist"
```

#### Vercel

零配置部署 Astro，自动检测项目类型并配置构建命令。

#### Cloudflare Pages

```bash
npx astro add cloudflare
```

```js
// astro.config.mjs
import cloudflare from '@astrojs/cloudflare';
export default defineConfig({
  output: 'server',
  adapter: cloudflare({ imageService: 'cloudflare' }),
});
```

#### GitHub Pages

```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

### 10.3 完整配置参考

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import tailwind from '@astrojs/tailwind';
import sitemap from '@astrojs/sitemap';
import netlify from '@astrojs/netlify';

export default defineConfig({
  // 站点信息
  site: 'https://example.com',
  base: '/',                       // 部署到子路径时设置

  // 渲染模式
  output: 'server',                // 'static' | 'server' | 'hybrid'
  adapter: netlify(),

  // 集成列表
  integrations: [
    react(),
    tailwind({ applyBaseStyles: false }),
    sitemap(),
  ],

  // 开发服务器
  server: {
    port: 4321,
    host: true,
  },

  // 构建配置
  build: {
    format: 'directory',           // 'directory' | 'file' | 'preserve'
    assets: '_assets',
    inlineStylesheets: 'auto',
  },

  // 路由重定向
  redirects: {
    '/old': '/new',
  },

  // i18n
  i18n: {
    defaultLocale: 'zh-CN',
    locales: ['zh-CN', 'en'],
    routing: { prefixDefaultLocale: false },
  },

  // 图片配置
  image: {
    domains: ['cdn.example.com'],
    remotePatterns: [{ protocol: 'https', hostname: '**.example.com' }],
  },

  // 预获取
  prefetch: { defaultStrategy: 'hover' },

  // Markdown 配置
  markdown: {
    syntaxHighlight: 'shiki',
    shikiConfig: { theme: 'github-dark' },
  },

  // Vite 透传配置
  vite: {
    resolve: { alias: { '@': '/src' } },
    ssr: { noExternal: ['some-package'] },
  },

  // 实验性功能
  experimental: {
    svg: true,
    contentIntellisense: true,
  },
});
```

### 10.4 性能优化清单

| 优化项 | 方法 |
|---|---|
| 减少 JS | 默认零 JS，仅在必要时用 `client:*` |
| 图片优化 | `<Image />` 组件自动压缩转格式 |
| 预获取 | `data-astro-prefetch` 属性 |
| 懒加载 | `client:visible` 延迟交互组件 |
| CSS 压缩 | 默认作用域样式，移除无用样式 |
| 字体优化 | 使用 Fontsource 或实验性 Font API |
| 打包分析 | `npm run build` 后检查 dist 大小 |

### 10.5 预防常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 样式不生效 | 作用域样式未穿透子组件 | 用 `:global()` 选择器 |
| 构建报 `import.meta.env` 错 | 环境变量未定义 | 检查 `.env` 文件和 `PUBLIC_` 前缀 |
| 图片不显示 | 远程域名未授权 | 在 `image.domains` 中添加 |
| SSR 404 | 未设置适配器 | `npx astro add <adapter>` |
| 类型报错 | 内容集合类型未同步 | `npx astro sync` |
| 客户端组件报错 | 使用了服务端 API | 将逻辑移到 `client:*` 组件或 `<script>` |

### 10.6 从其他框架迁移

#### 从 Next.js 迁移对照

| Next.js | Astro |
|---|---|
| `pages/` | `src/pages/` |
| `getStaticProps` | frontmatter 中 `await fetch()` |
| `getServerSideProps` | SSR + `Astro.request` |
| `_app.tsx` | 布局组件 |
| `next.config.js` | `astro.config.mjs` |
| `<Link>` | `<a>` 标签 |

#### 迁移策略

1. **逐页迁移**：从 Landing Page 开始
2. **复用组件**：现有 React/Vue 组件直接用 `client:*` 指令
3. **渐进增强**：先确保静态内容正常，再添加交互

2. 检查实验性标志是否变为正式 API
3. 运行测试确保原有功能正常

### 10.8 安全最佳实践

```astro
---
// ✅ 敏感操作在服务端
const apiKey = import.meta.env.SECRET_KEY;

// ✅ 自动 HTML 转义（防 XSS）
// <div>{userInput}</div>

// ⚠️ 仅在信任源使用
// <div set:html={trustedHtml} />
---
```

**环境变量命名规则**：
- `PUBLIC_*` → 客户端可用（如 `PUBLIC_SITE_URL`）
- 不加前缀 → 仅服务端可用（如 `DATABASE_URL`）
