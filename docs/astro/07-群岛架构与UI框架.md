## 第七章：群岛架构与 UI 框架集成

### 7.1 群岛架构核心概念

群岛架构在"静态 HTML 的海洋"中渲染"交互性的岛屿"。

每个岛屿独立在客户端水合（hydrate），可混合使用 React、Vue、Svelte 等不同框架。

### 7.2 客户端指令

使用 `client:*` 指令控制组件加载时机：

| 指令 | 行为 |
|---|---|
| `client:load` | 页面加载时立即激活 |
| `client:idle` | 浏览器空闲时激活 |
| `client:visible` | 组件进入视口时激活 |
| `client:media={query}` | 匹配媒体查询时激活 |
| `client:only` | 仅客户端渲染 |

```astro
<MobileMenu client:media="(max-width: 768px)" />
<Newsletter client:visible />
<Analytics client:idle />
```

### 7.3 React 集成

```bash
npx astro add react
```

```tsx
// src/components/Counter.tsx
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <button onClick={() => setCount(c => c - 1)}>-</button>
      <span>{count}</span>
      <button onClick={() => setCount(c => c + 1)}>+</button>
    </div>
  );
}
```

```astro
---
import Counter from '../components/Counter';
---

<Counter client:load />
```

### 7.4 Vue 集成

```bash
npx astro add vue
```

```vue
<script setup>
import { ref } from 'vue';
const newTodo = ref('');
const todos = ref([]);
function addTodo() {
  if (newTodo.value.trim()) {
    todos.value.push({ text: newTodo.value, done: false });
    newTodo.value = '';
  }
}
</script>

<template>
  <input v-model="newTodo" @keyup.enter="addTodo" />
  <ul>
    <li v-for="(todo, i) in todos" :key="i">
      {{ todo.text }}
    </li>
  </ul>
</template>
```

```astro
<TodoList client:visible />
```

### 7.6 SolidJS 集成

```bash
npx astro add solid
```

```tsx
import { createSignal, onCleanup } from 'solid-js';
export default function Clock() {
  const [time, setTime] = createSignal(new Date());
  const timer = setInterval(() => setTime(new Date()), 1000);
  onCleanup(() => clearInterval(timer));
  return <div>{time().toLocaleTimeString('zh-CN')}</div>;
}
```

### 7.8 岛屿间状态共享

```bash
npm install nanostores @nanostores/react
```

```js
// src/store/cart.js
import { atom } from 'nanostores';
export const cartItems = atom([]);
export function addToCart(item) {
  cartItems.set([...cartItems.get(), item]);
}
```

```jsx
import { useStore } from '@nanostores/react';
import { cartItems, addToCart } from '../store/cart';

export default function CartButton({ product }) {
  const items = useStore(cartItems);
  return (
    <button onClick={() => addToCart(product)}>
      购物车 ({items.length})
    </button>
  );
}
```

### 7.9 选择框架策略

| 场景 | 推荐 |
|---|---|
| 简单交互（开关、折叠） | Alpine.js |
| 中等复杂度 | Vue / Svelte |
| 复杂组件（图表、编辑器） | React |
| 高性能需求 | SolidJS |
