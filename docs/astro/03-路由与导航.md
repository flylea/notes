## 第三章：路由与导航

### 3.1 基于文件的路由系统

Astro 使用**基于文件的路由**，`src/pages/` 目录中的文件自动生成 URL 路由。无需任何路由配置文件。

#### 页面文件类型

`src/pages/` 下支持的文件类型：

| 文件类型 | 举例 | 说明 |
|---|---|---|
| `.astro` | `index.astro` | Astro 组件页面 |
| `.md` | `about.md` | Markdown 页面 |
| `.mdx` | `guide.mdx` | MDX 页面（可嵌入组件） |

#### 静态路由规则

```
src/pages/
├── index.astro              → /
├── about.astro              → /about
├── about/
│   └── index.astro          → /about        (同 about.astro 效果)
├── about/
│   └── me.astro             → /about/me
├── posts/
│   └── 1.md                 → /posts/1
├── contact.astro            → /contact
└── products/
    ├── index.astro          → /products
    └── category.astro       → /products/category
```

> 注意：`about.astro` 和 `about/index.astro` 会生成**相同的路由**，只能存在一个。

#### 页面导航

Astro 使用标准 HTML `<a>` 标签，无需框架特定的 `<Link>` 组件：

```astro
<nav>
  <a href="/">首页</a>
  <a href="/about">关于</a>
  <a href="/blog">博客</a>
</nav>
```

> 与 React Router / Next.js Link 不同，Astro 中直接使用 `<a>` 标签，因为默认是 MPA（多页应用）架构。

### 3.2 动态路由

使用文件名中的 `[param]` 方括号语法定义动态参数。

#### 基本动态路由

```
src/pages/
└── blog/
    └── [slug].astro         → 匹配 /blog/hello-world、/blog/post-2 等
```

```astro
---
// src/pages/blog/[slug].astro
export async function getStaticPaths() {
  const posts = await fetch('https://api.example.com/posts')
    .then(r => r.json());

  return posts.map(post => ({
    params: { slug: post.slug },   // 必须返回 params
    props: { post },                // 可选的额外数据
  }));
}

const { post } = Astro.props;
---

<article>
  <h1>{post.title}</h1>
  <time>{post.publishDate}</time>
  <p>{post.content}</p>
</article>
```

#### `getStaticPaths()` 详解

这是动态路由在静态模式下的核心函数：

```ts
export async function getStaticPaths() {
  return [
    {
      params: { slug: 'post-1' },       // 必需：路由参数
      props: { title: '文章一' },         // 可选：传递给页面的数据
    },
    {
      params: { slug: 'post-2' },
      props: { title: '文章二' },
    },
  ];
}
```

**返回值类型**：

```ts
interface StaticPath {
  params: Record<string, string | undefined>;
  props?: Record<string, any>;
}
```

#### 剩余参数（Rest Parameters）

使用 `[...name]` 匹配任意深度的路径：

```
src/pages/
└── docs/
    └── [...slug].astro
```

- `/docs` → `slug` 为 `undefined`
- `/docs/getting-started` → `slug` 为 `"getting-started"`
- `/docs/guides/routing` → `slug` 为 `"guides/routing"`

```astro
---
// src/pages/docs/[...slug].astro
export async function getStaticPaths() {
  const docs = await getDocs();

  return docs.map(doc => ({
    params: { slug: doc.path },
    props: { doc },
  }));
}

const { slug } = Astro.params;
---

<!-- 需要处理 slug 为 undefined 的情况（匹配顶级路由时）-->
```

#### 组合命名参数和剩余参数

```
src/pages/
└── [lang]/
    └── [org]/
        └── [repo]/
            └── tree/
                └── [branch]/
                    └── [...file].astro
```

匹配示例：`/zh/withastro/astro/tree/main/src/pages/index.astro`

#### 按需渲染的动态路由（SSR）

在 SSR 模式下，动态路由不需要 `getStaticPaths()`，直接匹配任意参数：

```astro
---
// src/pages/search/[query].astro
export const prerender = false;  // 按需渲染

const { query } = Astro.params;
const results = await searchAPI(query);
---

<h1>搜索 "{query}" 的结果</h1>
```

### 3.3 路由重定向

#### 配置级重定向（推荐）

在 `astro.config.mjs` 中配置：

```js
import { defineConfig } from 'astro/config';

export default defineConfig({
  redirects: {
    '/old-page': '/new-page',
    '/blog/[...slug]': '/articles/[...slug]',
    '/external': 'https://example.com',
  },
});
```

#### 组件级重定向

```astro
---
// 在页面组件中使用 Astro.redirect
if (someCondition) {
  return Astro.redirect('/login');
}

return Astro.redirect('/dashboard', 307);  // 指定状态码
---
```

### 3.4 页面优先级

当有多个文件匹配同一路由时，Astro 按以下优先级决定：

1. **静态路由**（如 `posts/create.astro`）优先于动态路由
2. **命名参数**（如 `[slug].astro`）优先于剩余参数
3. **剩余参数**（如 `[...slug].astro`）最后匹配

```
# 访问 /posts/hello
src/pages/posts/[slug].astro     ✅ 匹配
src/pages/posts/[...slug].astro  跳过（命名参数优先）
```

### 3.5 自定义输出格式

通过 `build.format` 配置输出文件格式：

```js
// astro.config.mjs
export default defineConfig({
  build: {
    format: 'directory',  // 默认：生成 /about/index.html
    // format: 'file',    // 生成 /about.html
    // format: 'preserve', // 保留原始文件扩展名 /about.astro → /about.html
  },
});
```

### 3.6 路由排除

某些文件不想成为路由页面时，使用下划线前缀：

```
src/pages/
├── _components/        ← 前缀 _ 不会被路由
│   └── SecretPage.astro
└── api/
    └── _utils.ts       ← 工具文件不会被路由
```

### 3.7 页面元数据与 SEO

#### 在布局中处理 SEO

```astro
---
// src/layouts/BaseLayout.astro
export interface Props {
  title: string;
  description: string;
  image?: string;
}

const { title, description, image } = Astro.props;
const canonicalURL = new URL(Astro.url.pathname, Astro.site);
---

<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <!-- 基本 SEO -->
    <title>{title}</title>
    <meta name="description" content={description} />
    <link rel="canonical" href={canonicalURL} />

    <!-- Open Graph -->
    <meta property="og:title" content={title} />
    <meta property="og:description" content={description} />
    <meta property="og:url" content={canonicalURL} />
    <meta property="og:type" content="website" />
    {image && <meta property="og:image" content={image} />}

    <!-- Twitter Card -->
    <meta name="twitter:card" content="summary_large_image" />
  </head>
  <body>
    <slot />
  </body>
</html>
```

#### 在页面中使用

```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout
  title="我的博客 — 首页"
  description="分享前端开发与 Astro 使用经验的技术博客"
>
  <h1>欢迎来到我的博客</h1>
</BaseLayout>
```

### 3.8 预获取（Prefetch）

预获取让即将访问的页面加载更快。

#### 链接级别预获取

```astro
<!-- 鼠标悬停时预获取 -->
<a href="/dashboard" data-astro-prefetch>仪表盘</a>

<!-- 页面加载时预获取 -->
<a href="/dashboard" data-astro-prefetch="load">仪表盘</a>

<!-- 进入视口时预获取 -->
<a href="/dashboard" data-astro-prefetch="viewport">仪表盘</a>

<!-- 移动端点击时预获取 -->
<a href="/dashboard" data-astro-prefetch="tap">仪表盘</a>
```

#### 全局预获取配置

```js
// astro.config.mjs
export default defineConfig({
  prefetch: {
    defaultStrategy: 'hover',   // hover | tap | viewport | load
    prefetchAll: false,         // 是否预获取所有链接
  },
});
```

### 3.10 路由完整示例：博客系统

整合所有路由知识，搭建完整博客路由：

```
src/pages/
├── index.astro                    → 首页（文章列表）
├── about.astro                    → 关于页
├── blog/
│   ├── index.astro                → 博客列表
│   ├── [slug].astro               → 单篇文章
│   ├── tags/
│   │   └── [tag].astro            → 按标签筛选
│   └── rss.xml.js                 → RSS 源
├── 404.astro                      → 404 页面
└── api/
    └── search.json.ts             → 搜索 API
```

```astro
---
// src/pages/index.astro
import BaseLayout from '../layouts/BaseLayout.astro';
import { getCollection } from 'astro:content';

// 获取最新的 5 篇文章
const posts = await getCollection('blog', ({ data }) => {
  return data.draft !== true;
});
const latestPosts = posts
  .sort((a, b) => b.data.publishDate.getTime() - a.data.publishDate.getTime())
  .slice(0, 5);
---

<BaseLayout title="我的博客">
  <h1>最新文章</h1>
  <div class="post-list">
    {latestPosts.map(post => (
      <article>
        <h2>
          <a href={`/blog/${post.slug}`}>{post.data.title}</a>
        </h2>
        <p>{post.data.description}</p>
        <time datetime={post.data.publishDate.toISOString()}>
          {post.data.publishDate.toLocaleDateString('zh-CN')}
        </time>
      </article>
    ))}
  </div>
  <a href="/blog" data-astro-prefetch>
    查看全部文章 →
  </a>
</BaseLayout>
```

### 本章小结

- **文件即路由**：`src/pages/` 下的文件自动成为页面
- **动态路由**：`[param]` 用于单层参数，`[...param]` 用于任意深度
- **`getStaticPaths()`**：静态模式下动态路由的必需函数
- **重定向**：可在配置文件或组件中使用 `Astro.redirect()`
- **预获取**：`data-astro-prefetch` 属性加速页面加载
- **下划线前缀**：`_private/` 目录不会被路由
