## Part 12 学习目标

完成本 Part 后，你应该能：

- [ ] 独立完成 Flutter App 的 Code Review，识别常见反模式
- [ ] 为真实项目选择合适的技术栈（状态管理/网络/数据库/路由）
- [ ] 从零搭建一个生产级 Flutter 项目模板
- [ ] 通过阅读优质开源项目源码持续提升 Flutter 能力
- [ ] 独立设计和实现小型 Flutter 项目（聊天/记账/天气等）
