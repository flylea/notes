# 自定义校验装饰器

## 什么时候需要自定义校验？

class-validator 提供了丰富的内置装饰器，但总有覆盖不到的业务规则：
- "用户名不能包含特殊字符"（正则不是最佳方案，语义更重要）
- "结束时间必须大于开始时间"
- "ISBN 必须唯一"

## 方式 1：ValidatorConstraint + @ValidatorConstraint

这是标准做法，适合**复用性高**的校验规则。

### 实例：用户名不可包含特殊字符

```typescript
import {
  ValidatorConstraint,
  ValidatorConstraintInterface,
  ValidationArguments,
  registerDecorator,
  ValidationOptions,
} from 'class-validator';

// Step 1: 定义校验逻辑
@ValidatorConstraint({ name: 'noSpecialChars', async: false })
export class NoSpecialCharsConstraint implements ValidatorConstraintInterface {
  validate(value: string, args: ValidationArguments): boolean {
    // 只允许字母、数字、下划线、横线
    return /^[\w-]+$/.test(value);
  }

  defaultMessage(args: ValidationArguments): string {
    return `${args.property} 只能包含字母、数字、下划线和横线`;
  }
}

// Step 2: 包装成装饰器
export function NoSpecialChars(validationOptions?: ValidationOptions) {
  return function (object: object, propertyName: string) {
    registerDecorator({
      target: object.constructor,
      propertyName,
      options: validationOptions,
      constraints: [],
      validator: NoSpecialCharsConstraint,
    });
  };
}
```

### 使用

```typescript
export class RegisterUserDto {
  @IsNotEmpty({ message: '用户名不能为空' })
  @NoSpecialChars({ message: '用户名包含非法字符' })
  username: string;
}
```

## 方式 2：异步校验（比如数据库查重）

`async: true` 允许返回 `Promise<boolean>`，适合需要查数据库的校验。

### 实例：用户名唯一性校验

```typescript
@ValidatorConstraint({ name: 'isUnique', async: true })
export class IsUniqueConstraint implements ValidatorConstraintInterface {
  async validate(value: string, args: ValidationArguments): Promise<boolean> {
    // 模拟数据库查询
    // 实际项目注入 PrismaService: 见下方"注入依赖"
    const existingUsers = ['admin', 'root', 'john']; // 模拟已有用户名
    return !existingUsers.includes(value);
  }

  defaultMessage(args: ValidationArguments): string {
    return `${args.property} "${args.value}" 已被占用`;
  }
}

export function IsUnique(validationOptions?: ValidationOptions) {
  return function (object: object, propertyName: string) {
    registerDecorator({
      target: object.constructor,
      propertyName,
      options: validationOptions,
      constraints: [],
      validator: IsUniqueConstraint,
    });
  };
}
```

### 使用

```typescript
export class RegisterUserDto {
  @IsUnique({ message: '用户名已被注册' })
  username: string;
}
```

## 异步校验中的依赖注入问题

上面的 `IsUniqueConstraint` 无法注入 `PrismaService`（它不是 Nest 的 Provider）。解决方案：

```typescript
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@ValidatorConstraint({ name: 'isUnique', async: true })
@Injectable()  // ← 关键！加上 @Injectable()
export class IsUniqueConstraint implements ValidatorConstraintInterface {
  constructor(private prisma: PrismaService) {}

  async validate(value: string, args: ValidationArguments): Promise<boolean> {
    // 从 args.object 获取 DTO 对象，args.property 获取字段名
    const [relatedProperty] = args.constraints;  // 可以传入额外参数
    const existing = await this.prisma.user.findUnique({
      where: { username: value },
    });
    return !existing;
  }

  defaultMessage(args: ValidationArguments): string {
    return `${args.property} "${args.value}" 已被占用`;
  }
}
```

然后在 AppModule 或对应的 Module 中把这个 Constraint 注册为 Provider：

```typescript
@Module({
  providers: [IsUniqueConstraint],  // 必须注册，否则 @Injectable() 不生效
})
export class UserModule {}
```

## 方式 3：简单的内联校验函数

如果校验逻辑只有一处使用，不必创建一个 class：

```typescript
import { Validate, ValidationArguments } from 'class-validator';

export class CreateBookDto {
  @Validate((value: string) => value?.startsWith('ISBN-'))
  isbn: string;

  // 或者内联 async：
  @Validate(async (value: string) => {
    const response = await fetch(`/api/check-isbn/${value}`);
    return response.ok;
  })
  anotherIsbn: string;
}
```

## 方式 4：类级别校验（跨字段校验）

当校验涉及多个字段之间的关系时，需要用类级别装饰器。

### 实例：结束时间必须大于开始时间

```typescript
import {
  ValidatorConstraint,
  ValidatorConstraintInterface,
  ValidationArguments,
  registerDecorator,
  ValidationOptions,
} from 'class-validator';

interface DateRange {
  startDate: string;
  endDate: string;
}

@ValidatorConstraint({ name: 'isDateRange', async: false })
export class IsDateRangeConstraint implements ValidatorConstraintInterface {
  validate(value: any, args: ValidationArguments): boolean {
    const obj = args.object as DateRange;
    if (!obj.startDate || !obj.endDate) return true;  // 让其他校验器检查非空
    return new Date(obj.endDate) > new Date(obj.startDate);
  }

  defaultMessage(args: ValidationArguments): string {
    return '结束时间必须大于开始时间';
  }
}
```

```typescript
// 类级别装饰器
export function IsDateRange(validationOptions?: ValidationOptions) {
  return function (object: object, propertyName: string) {
    registerDecorator({
      name: 'isDateRange',
      target: object.constructor,
      propertyName: propertyName,  // 应用在整个类上
      options: validationOptions,
      constraints: [],
      validator: IsDateRangeConstraint,
    });
  };
}
```

### 使用

```typescript
@IsDateRange({ message: '结束时间必须大于开始时间' })
export class DateRangeDto {
  startDate: string;
  endDate: string;
}
```

## 装饰器工厂模式

以上所有自定义装饰器都遵循**装饰器工厂**模式：

```typescript
function MyValidator(options?: ValidationOptions) {
  // 返回装饰器函数
  return function (object: object, propertyName: string) {
    registerDecorator({
      target: object.constructor,
      propertyName,
      options,       // ValidationOptions：message、groups、each 等
      constraints: [], // 传给 validate 的额外参数
      validator: MyConstraint,
    });
  };
}
```

## 实战：图书管理系统中的自定义校验

```typescript
// src/common/validators/is-book-status.validator.ts
@ValidatorConstraint({ name: 'isBookStatus', async: false })
export class IsBookStatusConstraint implements ValidatorConstraintInterface {
  validate(value: string): boolean {
    const validStatuses = ['available', 'borrowed', 'reserved'];
    return validStatuses.includes(value);
  }

  defaultMessage(args: ValidationArguments): string {
    return `${args.property} 必须是 available/borrowed/reserved 之一`;
  }
}

export function IsBookStatus(validationOptions?: ValidationOptions) {
  return function (object: object, propertyName: string) {
    registerDecorator({
      target: object.constructor,
      propertyName,
      options: validationOptions,
      validator: IsBookStatusConstraint,
    });
  };
}

// 使用
export class UpdateBookStatusDto {
  @IsNotEmpty()
  @IsBookStatus()
  status: string;
}
```

> 自定义校验让校验规则"语义化"——读代码就知道这个字段在做什么校验，而不需要用正则去"翻译"。
