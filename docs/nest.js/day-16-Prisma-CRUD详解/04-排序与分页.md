# 排序与分页

## orderBy — 排序

```typescript
// 单字段排序
prisma.book.findMany({
  orderBy: { createdAt: 'desc' },  // 最新在前
});
// 'asc' 升序, 'desc' 降序

// 多字段排序
prisma.book.findMany({
  orderBy: [
    { status: 'asc' },     // 先按状态
    { createdAt: 'desc' }, // 再按时间
  ],
});

// 关联字段排序
prisma.book.findMany({
  orderBy: {
    borrows: { _count: 'desc' },  // 按借阅次数排序（热门排行）
  },
});
```

## 分页（skip + take）

```typescript
// 基础分页
prisma.book.findMany({
  skip: (page - 1) * size,
  take: size,
});

// 下一页（推荐用 Cursor，避免 offset 性能问题）
prisma.book.findMany({
  take: 10,
  skip: 1,   // 跳过第 1 条后的（不要 cursor: { id: 10 }）
});

// 游标分页（高性能）
prisma.book.findMany({
  take: 10,
  cursor: { id: 20 },  // 从 id=20 之后开始
  skip: 1,             // 跳过分页标记本身（即 id=20 这条）
});
```

## 分页响应模式

```typescript
// Service 中的分页逻辑
async list(query: { page: number; size: number; keyword?: string }) {
  const { page = 1, size = 10, keyword } = query;

  const [list, total] = await Promise.all([
    this.prisma.book.findMany({
      where: keyword
        ? { title: { contains: keyword } }
        : undefined,
      skip: (page - 1) * size,
      take: size,
      orderBy: { createdAt: 'desc' },
    }),
    this.prisma.book.count({
      where: keyword
        ? { title: { contains: keyword } }
        : undefined,
    }),
  ]);

  return { list, total, page, size };
}
```

> `findMany` 和 `count` 放在 `Promise.all` 中并行执行——总耗时 = 两者中最长的时间，而不是相加。

## 游标分页 vs 偏移分页

| | skip/take (Offset) | cursor (Cursor) |
|---|---|---|
| 原理 | 跳过 N 行 | 从特定位置开始 |
| 性能 | 大页码时慢（需扫描前面的行） | 始终快速（走索引） |
| 实时性 | 新增数据会导致重复 | 数据流稳定 |
| 使用场景 | 管理后台（数据量可控） | Feed 流（无限滚动） |
