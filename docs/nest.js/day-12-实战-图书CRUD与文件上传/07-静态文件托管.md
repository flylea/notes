# 静态文件托管

## 问题

文件上传到 `./uploads/covers/` 后，前端无法直接访问。比如：

```
文件路径：./uploads/covers/2026-05-10/1715344200_abc.jpg
前端需要：http://localhost:3000/uploads/covers/2026-05-10/1715344200_abc.jpg
```

## 解决方案：ServeStaticModule 或 Express 静态文件中间件

### 方法 1：Express 内置方式（最简单）

```typescript
// main.ts
import { NestExpressApplication } from '@nestjs/platform-express';
import { join } from 'path';

async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule);

  // 托管 uploads 目录为静态文件服务
  app.useStaticAssets(join(__dirname, '..', 'uploads'), {
    prefix: '/uploads/',  // 访问前缀
  });

  await app.listen(3000);
}
```

访问方式：
```
http://localhost:3000/uploads/covers/2026-05-10/xxx.jpg
```

### 方法 2：多个静态目录

```typescript
// 托管多个目录
app.useStaticAssets(join(__dirname, '..', 'uploads'), { prefix: '/uploads/' });
app.useStaticAssets(join(__dirname, '..', 'public'), { prefix: '/public/' });
// /uploads/ 用于上传文件
// /public/ 用于静态资源（favicon、默认头像等）
```

### 方法 3：ServeStaticModule（Nest 风格）

```bash
npm install @nestjs/serve-static
```

```typescript
// app.module.ts
import { ServeStaticModule } from '@nestjs/serve-static';
import { join } from 'path';

@Module({
  imports: [
    ServeStaticModule.forRoot({
      rootPath: join(__dirname, '..', 'uploads'),
      serveRoot: '/uploads',  // URL 前缀
      serveStaticOptions: {
        index: false,          // 不查找 index.html
        maxAge: '7d',          // 缓存 7 天
      },
    }),
  ],
})
export class AppModule {}
```

## 安全考量

### 1. 限制允许的文件类型

```typescript
app.useStaticAssets(join(__dirname, '..', 'uploads'), {
  prefix: '/uploads/',
  setHeaders: (res, path, stat) => {
    // 只允许图片文件
    const ext = require('path').extname(path).toLowerCase();
    const allowedExts = ['.jpg', '.jpeg', '.png', '.gif', '.webp'];

    if (!allowedExts.includes(ext)) {
      res.status(403).send('File type not allowed');
    }
  },
});
```

### 2. 防止目录遍历攻击

```typescript
import { join, normalize, resolve } from 'path';

// 自定义静态文件中间件，检查路径安全性
app.use('/uploads', (req, res, next) => {
  const requestedPath = req.path;
  const safePath = normalize(requestedPath).replace(/^(\.\.[\/\\])+/, '');
  const fullPath = resolve(join(__dirname, '..', 'uploads', safePath));

  if (!fullPath.startsWith(resolve(join(__dirname, '..', 'uploads')))) {
    return res.status(403).send('Forbidden');
  }

  next();
});
```

### 3. 生产环境建议

```
开发环境：app.useStaticAssets → 直接访问本地文件
生产环境：
  ├── Nginx 反向代理 + 静态文件托管（推荐，Day 29详讲）
  ├── CDN 加速 静态资源
  └── OSS/MinIO/RustFS 托管文件（Day 25详讲）
```

## 配置 CORS + 静态文件

```typescript
async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule);

  // 1. CORS 必须放在静态文件之前
  app.enableCors({ origin: true });

  // 2. 静态文件托管
  app.useStaticAssets(join(__dirname, '..', 'uploads'), {
    prefix: '/uploads/',
  });

  await app.listen(3000);
}
```

> 开发环境用 `useStaticAssets` 足够。生产环境强烈建议用 Nginx 托管静态文件（性能更好，且 Node.js 不至于被大文件下载阻塞）。
