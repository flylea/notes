# 表关系设计

## 三种核心关系

```
一对一 (One-to-One):   User ──── UserProfile
一对多 (One-to-Many):  User ──── Book (一个用户可以创建多本书)
多对多 (Many-to-Many): Book ──── Tag (一本书可以有多个标签，一个标签可以对应多本书)
```

## 一对一：User ↔ UserProfile

```sql
-- MySQL
CREATE TABLE user_profiles (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL UNIQUE,  -- UNIQUE 保证一对一
  bio TEXT,
  avatar VARCHAR(255),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

Prisma 中的一对一：

```prisma
model User {
  id       BigInt  @id @default(autoincrement())
  username String  @unique
  profile  UserProfile?
}

model UserProfile {
  id      BigInt @id @default(autoincrement())
  bio     String?
  avatar  String?
  user    User   @relation(fields: [userId], references: [id])
  userId  BigInt @unique  // ← @unique 保证一对一
}
```

## 一对多：User ↔ BorrowRecord

```sql
-- 一个用户可以有多条借阅记录
CREATE TABLE borrow_records (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL,
  book_id BIGINT NOT NULL,
  borrowed_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (book_id) REFERENCES books(id)
);
```

Prisma 中的一对多：

```prisma
model User {
  id      BigInt          @id @default(autoincrement())
  borrows BorrowRecord[]  // User 拥有多条借阅记录
}

model BorrowRecord {
  id       BigInt    @id @default(autoincrement())
  user     User      @relation(fields: [userId], references: [id])
  userId   BigInt
  book     Book      @relation(fields: [bookId], references: [id])
  bookId   BigInt
  borrowedAt DateTime @default(now())
}
```

## 多对多：Book ↔ Tag

### 隐式中建表（Prisma 自动管理）

```prisma
model Book {
  id   BigInt @id @default(autoincrement())
  tags Tag[]  // ← Prisma 自动创建 _BookToTag 中间表
}

model Tag {
  id    BigInt @id @default(autoincrement())
  name  String @unique
  books Book[] // ← Prisma 自动创建 _BookToTag 中间表
}
```

### 显式中建表（需要额外字段）

```prisma
model Book {
  id       BigInt        @id @default(autoincrement())
  bookTags BookTag[]     // 显式引用中间表
}

model Tag {
  id       BigInt    @id @default(autoincrement())
  name     String    @unique
  bookTags BookTag[]
}

model BookTag {
  book     Book     @relation(fields: [bookId], references: [id])
  bookId   BigInt
  tag      Tag      @relation(fields: [tagId], references: [id])
  tagId    BigInt
  addedAt  DateTime @default(now())  // ← 中间表的额外字段

  @@id([bookId, tagId])  // 复合主键
}
```

## 外键约束操作（onDelete）

```prisma
model BorrowRecord {
  user   User  @relation(fields: [userId], references: [id], onDelete: Cascade)
  userId BigInt
  // onDelete: Cascade → 删除用户时同时删除其所有借阅记录
  // onDelete: SetNull → 删除用户时将 userId 设为 NULL
  // onDelete: Restrict → 有借阅记录时禁止删除用户
}
```

## 图书管理系统的完整关系图

```
User (1) ───────── (N) BorrowRecord (N) ──────── (1) Book
  │                        │
  │                        ├── userId (FK → User.id)
  │                        ├── bookId (FK → Book.id)
  │                        ├── borrowedAt
  │                        └── returnedAt
  │
  └── (N) BookTag 中间表
            ├── bookId (FK → Book.id)
            ├── tagId (FK → Tag.id)
            └── addedAt
```
