## 学习建议

- 如果你时间有限，**至少读完 02 和 04**——框架选型和认知迁移是关键决策
- 每个子文件约 10 分钟阅读时间，今日总耗时约 50 分钟
- 带着一个问题读：**"如果让我用 Express 写一个图书管理系统，会遇到哪些痛点？"**——这些痛点就是 Nest 存在的理由
