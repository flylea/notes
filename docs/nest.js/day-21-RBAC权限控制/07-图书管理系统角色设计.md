# 图书管理系统角色与权限初始化

## 角色初始化 Seed

```typescript
// prisma/seed.ts（在现有 seed 基础上添加 RBAC 初始化）

async function initRBAC() {
  console.log('初始化 RBAC 权限系统...');

  // ==================== 创建权限 ====================
  const permissionsData = [
    // 图书权限
    { code: 'book:read',   name: '查看图书', resource: 'book', action: 'read' },
    { code: 'book:create', name: '新增图书', resource: 'book', action: 'create' },
    { code: 'book:update', name: '编辑图书', resource: 'book', action: 'update' },
    { code: 'book:delete', name: '删除图书', resource: 'book', action: 'delete' },
    { code: 'book:borrow', name: '借阅图书', resource: 'book', action: 'borrow' },
    { code: 'book:return', name: '归还图书', resource: 'book', action: 'return' },

    // 用户权限
    { code: 'user:read',   name: '查看用户', resource: 'user', action: 'read' },
    { code: 'user:create', name: '创建用户', resource: 'user', action: 'create' },
    { code: 'user:update', name: '编辑用户', resource: 'user', action: 'update' },
    { code: 'user:delete', name: '删除用户', resource: 'user', action: 'delete' },

    // 分类权限
    { code: 'category:read',   name: '查看分类', resource: 'category', action: 'read' },
    { code: 'category:create', name: '新增分类', resource: 'category', action: 'create' },
    { code: 'category:delete', name: '删除分类', resource: 'category', action: 'delete' },

    // 借阅管理权限
    { code: 'borrow:read',   name: '查看借阅记录', resource: 'borrow', action: 'read' },
    { code: 'borrow:return', name: '确认归还',     resource: 'borrow', action: 'return' },
  ];

  const permissions: Record<string, number> = {};

  for (const p of permissionsData) {
    const perm = await prisma.permission.create({ data: p });
    permissions[p.code] = perm.id;
  }

  console.log(`  ✅ 创建了 ${permissionsData.length} 个权限`);

  // ==================== 创建角色 ====================
  const userRole = await prisma.role.create({
    data: {
      code: 'USER',
      name: '普通用户',
      description: '默认角色，可以浏览和借阅图书',
      isSystem: true,
    },
  });

  const librarianRole = await prisma.role.create({
    data: {
      code: 'LIBRARIAN',
      name: '图书管理员',
      description: '管理图书和分类',
      isSystem: true,
    },
  });

  const adminRole = await prisma.role.create({
    data: {
      code: 'ADMIN',
      name: '系统管理员',
      description: '拥有全部权限',
      isSystem: true,
    },
  });

  console.log('  ✅ 创建了 3 个角色');

  // ==================== 分配权限到角色 ====================
  // 普通用户权限
  const userPermissions = [
    'book:read', 'book:borrow', 'book:return',
  ];

  // 图书管理员权限（继承 USER + 额外权限）
  const librarianPermissions = [
    ...userPermissions,
    'book:create', 'book:update',
    'category:read', 'category:create',
    'borrow:read',
  ];

  // 管理员权限（全部权限）
  const adminPermissions = [
    ...librarianPermissions,
    'book:delete',
    'category:delete',
    'user:read', 'user:create', 'user:update', 'user:delete',
    'borrow:return',
  ];

  for (const permCode of userPermissions) {
    await prisma.rolePermission.create({
      data: { roleId: userRole.id, permissionId: permissions[permCode] },
    });
  }

  for (const permCode of librarianPermissions) {
    await prisma.rolePermission.create({
      data: { roleId: librarianRole.id, permissionId: permissions[permCode] },
    });
  }

  for (const permCode of adminPermissions) {
    await prisma.rolePermission.create({
      data: { roleId: adminRole.id, permissionId: permissions[permCode] },
    });
  }

  console.log('  ✅ 权限已分配到角色');

  // ==================== 分配角色到用户 ====================
  // admin → ADMIN 角色
  await prisma.userRole.create({
    data: { userId: 1, roleId: adminRole.id },
  });

  // alice → USER 角色
  await prisma.userRole.create({
    data: { userId: 2, roleId: userRole.id },
  });

  // bob → USER 角色
  await prisma.userRole.create({
    data: { userId: 3, roleId: userRole.id },
  });

  console.log('  ✅ 角色已分配到用户');
}
```

## RBAC 创建后的项目结构

```
src/
├── auth/
│   ├── auth.module.ts
│   ├── auth.service.ts         # 登录/刷新 Token
│   ├── auth.guard.ts            # 认证守卫
│   ├── permission.guard.ts      # 权限守卫
│   ├── permission.decorator.ts  # @RequirePermission
│   ├── is-public.decorator.ts   # @IsPublic
│   ├── user.decorator.ts        # @CurrentUser
│   ├── decorators/
│   │   └── auth.decorator.ts    # 组合装饰器
│   └── jwt.module.ts            # JWT 模块

│   ├── redis.module.ts
│   └── redis.service.ts
├── prisma/
├── user/
├── book/
└── borrow/
```

## 权限验证测试

```bash
# 管理员创建图书——成功
curl -X POST http://localhost:3000/book/create \
  -H "Authorization: Bearer <admin_token>" \
  -d '{"title":"新书","author":"作者"}'
# → 201 Created ✅

# 普通用户创建图书——失败
curl -X POST http://localhost:3000/book/create \
  -H "Authorization: Bearer <alice_token>" \
  -d '{"title":"新书","author":"作者"}'
# → 403 Forbidden
# → { "message": "需要权限: book:create" } ❌

# 普通用户借书——成功
curl -X POST http://localhost:3000/borrow/borrow \
  -H "Authorization: Bearer <alice_token>" \
  -d '{"bookId":"1"}'
# → 201 Created ✅
```

> 现在系统同时拥有了"认证"（知道你是谁）和"授权"（知道你能做什么）两层保护。
