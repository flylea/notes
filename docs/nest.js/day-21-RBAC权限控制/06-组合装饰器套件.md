# 组合装饰器：@RequireLogin + @RequirePermission

## 为什么要组合

```typescript
// 当前每个接口需要写多个装饰器
@Post('create')
@UseGuards(AuthGuard, PermissionGuard)
@RequirePermission('book:create')
async create() {}

// 如果 AuthGuard 已全局注册，PermissionGuard 也全局注册
// 只需要：
@Post('create')
@RequirePermission('book:create')
async create() {}

// 但有些接口只需要登录，不需要特定权限
// @RequireLogin() 本质上是"需要登录"的语义标记
```

## 创建组合装饰器套件

```typescript
// src/auth/decorators/auth.decorator.ts
import { applyDecorators, SetMetadata } from '@nestjs/common';
import { PERMISSIONS_KEY } from '../permission.decorator';
import { IS_PUBLIC_KEY } from '../is-public.decorator';

// ==================== @RequireLogin ====================
// 标记接口需要登录（默认所有接口都需要，这个装饰器主要是语义表达）
// 如果你把 AuthGuard 全局注册，所有接口默认需要登录，这个装饰器可以不写。
// 如果你想让某些接口可以是"公开或登录后查看更多"，这个装饰器就有用。

export const REQUIRE_LOGIN_KEY = 'requireLogin';

export const RequireLogin = () => SetMetadata(REQUIRE_LOGIN_KEY, true);

// ==================== @RequirePermission ====================
// 标记接口需要特定权限
export const RequirePermission = (...permissions: string[]) =>
  SetMetadata(PERMISSIONS_KEY, permissions);

// ==================== @RequirePermissions ====================
// 别名，复数形式更自然
export const RequirePermissions = RequirePermission;

// ==================== @AdminOnly ====================
// 只有 ADMIN 角色可访问
export const AdminOnly = () =>
  applyDecorators(
    SetMetadata(PERMISSIONS_KEY, ['admin:access']),
    // 可以添加额外逻辑
  );

// ==================== @PublicOrAuth ====================
// 公开访问，但如果登录了可以获取更多数据
// 用于图书列表：未登录可看，登录后可看借阅状态
export const PublicOrAuth = () =>
  SetMetadata('publicOrAuth', true);
```

## 使用示例

```typescript
// src/book/book.controller.ts
@Controller('book')
export class BookController {
  @Get('list')
  @IsPublic()
  async list() {
    // 任何人都可以看图书列表
  }

  @Get('detail')
  @IsPublic()
  async detail() {
    // 任何人都可以看图书详情
  }

  @Post('create')
  @RequirePermissions('book:create')
  async create() {
    // 需要有新增图书权限
  }

  @Post('update')
  @RequirePermissions('book:update')
  async update() {
    // 需要有编辑图书权限
  }

  @Post('delete')
  @RequirePermissions('book:delete')
  async delete() {
    // 需要有删除图书权限
  }
}

// src/user/user.controller.ts
@Controller('user')
export class UserController {
  @Post('register')
  @IsPublic()
  async register() {}

  @Post('login')
  @IsPublic()
  async login() {}

  @Get('profile')
  // 不需要 @RequirePermission —— 登录用户都能看自己的资料
  async profile(@CurrentUser() user: JwtPayload) {
    return this.userService.findById(user.sub);
  }
}

// src/borrow/borrow.controller.ts
@Controller('borrow')
export class BorrowController {
  @Post('borrow')
  @RequirePermissions('book:borrow')
  async borrow() {}

  @Post('return')
  @RequirePermissions('book:return')
  async returnBook() {}

  @Get('my-borrows')
  // 只需要登录，不需要特定权限
  async myBorrows(@CurrentUser('sub') userId: number) {
    return this.borrowService.getMyBorrows(userId);
  }
}
```

## 装饰器决策树

```
这个接口需要认证吗？
    │
    否 → @IsPublic()
    │
    是 → 需要特定权限吗？
              │
              否 → 不用写装饰器（默认需要登录即可）
              │
              是 → @RequirePermission('xxx:xxx')
                        │
                        单个权限够了 → 写一个
                        需要多个 OR 关系 → 传多个参数
                        ADMIN 专属 → @AdminOnly()
```
