# Day 30：微服务入门与 30 天回顾

## 今日概览

最后一天不再深挖细节，而是帮你建立"微服务全景图"。了解微服务的适用边界、NestJS 支持的通信模式、以及整个 30 天学习路线的知识图谱。

## 学习目标

- 理解微服务和单体的各自适用场景，不盲从
- 了解 NestJS 的 4 种微服务传输层（TCP/Redis/RabbitMQ/gRPC）
- 了解消息队列的削峰填谷模式
- 了解 WebSocket 和 SSE 的实时通信方案
- 回顾 30 天学习路线，明确进阶方向
