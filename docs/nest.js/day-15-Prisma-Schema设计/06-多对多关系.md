# 多对多关系

## 隐式 vs 显式

Prisma 支持两种多对多：

```prisma
// 方式 1：隐式中间表（Prisma 自动管理）
model Book {
  id   BigInt @id @default(autoincrement())
  tags Tag[]  // ← Prisma 自动创建 _BookToTag 表
}

model Tag {
  id    BigInt @id @default(autoincrement())
  name  String @unique
  books Book[]
}

// 方式 2：显式中间表（需要额外字段时）
model Book {
  id       BigInt    @id @default(autoincrement())
  bookTags BookTag[]
}

model Tag {
  id       BigInt    @id @default(autoincrement())
  name     String    @unique
  bookTags BookTag[]
}

model BookTag {
  book    Book     @relation(fields: [bookId], references: [id])
  bookId  BigInt
  tag     Tag      @relation(fields: [tagId], references: [id])
  tagId   BigInt
  addedAt DateTime @default(now())  // ← 中间表的额外字段（隐式做不到）

  @@id([bookId, tagId])  // 复合主键
}
```

## 何时用显式中间表？

- 需要记录关联时的额外信息（如"何时打标签"、"谁打的"）
- 需要直接查询中间表
- 需要中间表有独立 ID

## 图书管理系统实例：Book ↔ Category

```prisma
model Book {
  id            BigInt          @id @default(autoincrement())
  title         String
  bookCategories BookCategory[]
}

model Category {
  id            BigInt          @id @default(autoincrement())
  name          String          @unique
  bookCategories BookCategory[]
}

model BookCategory {
  book     Book     @relation(fields: [bookId], references: [id])
  bookId   BigInt
  category Category @relation(fields: [categoryId], references: [id])
  categoryId BigInt

  @@id([bookId, categoryId])
}
```
