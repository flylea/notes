# 字段类型与修饰符

## Prisma 字段类型一览

| Prisma 类型 | 描述 | MySQL 映射 | PostgreSQL 映射 |
|------------|------|-----------|----------------|
| `String` | 字符串 | `VARCHAR(191)` | `TEXT` |
| `Boolean` | 布尔 | `TINYINT(1)` | `BOOLEAN` |
| `Int` | 整数 | `INT` | `INTEGER` |
| `BigInt` | 大整数 | `BIGINT` | `BIGINT` |
| `Float` | 浮点 | `DOUBLE` | `DOUBLE PRECISION` |
| `Decimal` | 精确小数 | `DECIMAL(65,30)` | `DECIMAL(65,30)` |
| `DateTime` | 日期时间 | `DATETIME(3)` | `TIMESTAMP(3)` |
| `Json` | JSON | `JSON` | `JSONB` |
| `Bytes` | 二进制 | `LONGBLOB` | `BYTEA` |

## 字段修饰符

| 修饰符 | 含义 | 示例 |
|--------|------|------|
| `?` | 可选字段（NULL） | `email String?` |
| `[]` | 列表/数组 | `tags String[]` |
| `@id` | 主键 | `@id` |
| `@unique` | 唯一约束 | `@unique` |
| `@default(val)` | 默认值 | `@default(now())` |
| `@updatedAt` | 自动更新修改时间 | `@updatedAt` |
| `@map(name)` | 映射到数据库列名 | `@map("created_at")` |
| `@db.Type` | 原生数据库类型 | `@db.VarChar(50)` |

## 字段类型选择指南

```prisma
model Book {
  id          BigInt    @id @default(autoincrement())  // ID 用 BigInt（支持大数据量）
  title       String    @db.VarChar(100)               // 短文本用 VarChar
  description String?   @db.Text                       // 长文本用 Text
  price       Decimal   @db.Decimal(10, 2)             // 金额用 Decimal（精确）
  rating      Float?                                    // 评分用 Float
  isActive    Boolean   @default(true)                  // 状态用 Boolean
  publishedAt DateTime?                                 // 可选日期
  metadata    Json?                                     // 动态字段用 Json
  cover       Bytes?                                    // 图片二进制（但更推荐存 URL）
  tags        String[]                                  // 数组（仅 PostgreSQL）
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
}
```

## 复合属性（类级别）

```prisma
model User {
  id       Int    @id
  username String
  email    String

  @@unique([username, email])  // 组合唯一：用户名+邮箱不重复
  @@index([email])             // 单列索引
  @@index([username, email])   // 复合索引
  @@map("users")               // 映射到数据库表名
}
```

## @map 和 @@map — 控制实际的表名和列名

```prisma
model UserAccount {          // Prisma 中的模型名（JS/TS 中使用）
  id       Int    @id
  userName String @map("user_name")  // JS 中用 userName，数据库列是 user_name

  @@map("user_accounts")     // Prisma 中用 UserAccount，数据库表是 user_accounts
}
```

> Prisma 模型名默认转为 PascalCase，表名默认用模型名。`@@map` 让数据库表名更符合 DBA 规范。
