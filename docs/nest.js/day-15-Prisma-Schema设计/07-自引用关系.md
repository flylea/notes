# 自引用关系

## 概念

自引用关系是指**同一张表内的行引用同一张表的其他行**。最经典的例子：评论回复。

## 基本结构

```prisma
model Comment {
  id       BigInt    @id @default(autoincrement())
  content  String

  parentId  BigInt?    // 父评论 ID（可空——顶级评论没有父评论）
  parent    Comment?   @relation("CommentReply", fields: [parentId], references: [id])
  children  Comment[]  @relation("CommentReply")  // 子评论
}
```

## @relation 命名是关键

```prisma
// ❌ 错误：同一个 model 上的两个关系会有歧义
model User {
  // Prisma 报错：Ambiguous relation detected
}

// ✅ 正确：用 name 区分
model Employee {
  id        BigInt     @id @default(autoincrement())
  name      String

  managerId BigInt?
  manager   Employee?  @relation("Management", fields: [managerId], references: [id])
  staff     Employee[] @relation("Management")
}
```

## 图书管理系统实例：分类层级

```prisma
model Category {
  id       BigInt      @id @default(autoincrement())
  name     String
  parentId BigInt?
  parent   Category?   @relation("CategoryTree", fields: [parentId], references: [id], onDelete: SetNull)
  children Category[]  @relation("CategoryTree")
}
```

数据示例：
```
编程 (id=1, parentId=null)
  ├── 前端 (id=2, parentId=1)
  │   ├── Vue (id=4, parentId=2)
  │   └── React (id=5, parentId=2)
  └── 后端 (id=3, parentId=1)
      └── NestJS (id=6, parentId=3)
```
