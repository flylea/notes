# 自动请求日志 Interceptor

## 需求

每个请求自动打印一行包含以下信息的日志：

```
[2026-05-10T14:30:00.000Z] POST /user/register 201 45ms - ::1
```

- 时间戳
- 请求方法和路径
- 响应状态码
- 处理耗时
- 客户端 IP

## 完整实现

```typescript
import {
  Injectable,
  NestInterceptor,
  ExecutionContext,
  CallHandler,
  Logger,
} from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { Request, Response } from 'express';

@Injectable()
export class RequestLoggingInterceptor implements NestInterceptor {
  private readonly logger = new Logger('HTTP');

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const ctx = context.switchToHttp();
    const request = ctx.getRequest<Request>();
    const response = ctx.getResponse<Response>();

    const { method, originalUrl, ip } = request;
    const userAgent = request.get('user-agent') || '';
    const startTime = Date.now();

    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - startTime;
        const { statusCode } = response;

        this.logger.log(
          `${method} ${originalUrl} ${statusCode} ${duration}ms - ${ip} - ${userAgent.slice(0, 50)}`,
        );

        // 慢请求预警
        if (duration > 1000) {
          this.logger.warn(
            `SLOW REQUEST: ${method} ${originalUrl} — ${duration}ms`,
          );
        }
      }),
    );
  }
}
```

输出示例：

```
[HTTP] POST /user/register 201 45ms - ::1 - Mozilla/5.0 (Windows NT 10.0; Win64; x64)
[HTTP] GET /book/list?keyword=Nest&page=1 200 3ms - ::1 - Mozilla/5.0
[HTTP] POST /user/login 400 1ms - 192.168.1.100 - PostmanRuntime/7.32.0
[WARN] SLOW REQUEST: POST /book/import — 2500ms
```

## 扩展：查询参数脱敏

```typescript
// 对密码等敏感字段打码
function sanitizeUrl(url: string): string {
  return url.replace(/password=[^&]*/, 'password=***');
}

// 在 tap 中使用
this.logger.log(
  `${method} ${sanitizeUrl(originalUrl)} ${statusCode} ${duration}ms`,
);
```

## 扩展：结构化日志

```typescript
tap(() => {
  const logEntry = {
    timestamp: new Date().toISOString(),
    method,
    url: originalUrl,
    statusCode: response.statusCode,
    duration: `${Date.now() - startTime}ms`,
    ip,
    userAgent: userAgent.slice(0, 100),
  };

  // 控制台输出
  this.logger.log(JSON.stringify(logEntry));

  // 或者写入文件/Winston（Day 23 详讲）
});
```

## 扩展：异常日志

```typescript
return next.handle().pipe(
  tap({
    next: () => {
      // 正常响应
      this.logger.log(`${method} ${originalUrl} ${response.statusCode} ${Date.now() - startTime}ms`);
    },
    error: (error) => {
      // 异常响应
      const status = error?.status || error?.statusCode || 500;
      this.logger.error(
        `${method} ${originalUrl} ${status} ${Date.now() - startTime}ms - ${error.message}`,
      );
    },
  }),
);
```

## 扩展：按接口分级日志

```typescript
tap(() => {
  const duration = Date.now() - startTime;

  if (duration > 3000) {
    this.logger.error(`CRITICAL: ${method} ${originalUrl} ${duration}ms`);
  } else if (duration > 1000) {
    this.logger.warn(`SLOW: ${method} ${originalUrl} ${duration}ms`);
  } else if (response.statusCode >= 400) {
    this.logger.warn(`ERROR: ${method} ${originalUrl} ${response.statusCode}`);
  } else {
    this.logger.log(`${method} ${originalUrl} ${response.statusCode} ${duration}ms`);
  }
}),
```

## 全局注册

```typescript
// main.ts
app.useGlobalInterceptors(new RequestLoggingInterceptor());
```

> 请求日志是任何后端项目的必需品。用一个 Interceptor 集中处理，比在每个 Controller 里打 `console.log` 干净 100 倍。
