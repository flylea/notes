# Nest 生命周期钩子全景

## 一个 Nest 应用的生命周期

```
启动阶段                        运行阶段                       关闭阶段
┌─────────────────────┐    ┌──────────────┐    ┌─────────────────────┐
│ onModuleInit         │    │              │    │ onModuleDestroy      │
│  ↓                   │    │  处理请求    │    │  ↓                   │
│ onApplicationBootstrap│    │  ↑↓↑↓↑↓     │    │ beforeApplicationShutdown│
│  ↓                   │    │              │    │  ↓                   │
│ 启动完成 ✓            │    └──────────────┘    │ onApplicationShutdown │
└─────────────────────┘                        └─────────────────────┘
```

## 全部钩子一览

| 钩子 | 阶段 | 调用时机 | 典型用途 |
|------|------|---------|---------|
| `onModuleInit()` | 启动 | 模块初始化后 | 连接数据库、初始化连接池 |
| `onApplicationBootstrap()` | 启动 | 所有模块初始化后 | 预热缓存、启动定时任务 |
| `onModuleDestroy()` | 关闭 | 模块销毁前（SIGTERM） | 关闭数据库连接 |
| `beforeApplicationShutdown()` | 关闭 | 所有 onModuleDestroy 之后 | 等待正在处理的请求完成 |
| `onApplicationShutdown()` | 关闭 | 最后执行 | 清理临时文件、发送监控告警 |

## 实现方式

```typescript
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';

@Injectable()
export class PrismaService
  extends PrismaClient
  implements OnModuleInit, OnModuleDestroy
{
  async onModuleInit() {
    await this.$connect();  // 应用启动时连接数据库
    console.log('数据库已连接');
  }

  async onModuleDestroy() {
    await this.$disconnect();  // 应用关闭时断开连接
    console.log('数据库已断开');
  }
}
```

## 执行顺序

当一个模块中有多个生命周期实现者时，执行顺序：

```
启动：模块 A 全部 onModuleInit → 模块 B 全部 onModuleInit → (递归)
     → 全部 onApplicationBootstrap

关闭：全部 onModuleDestroy（并行）
     → 全部 beforeApplicationShutdown（并行）
     → 全部 onApplicationShutdown（并行）
```

## 常见应用场景

### 1. 启动时连接数据库（PrismaService）

```typescript
async onModuleInit() {
  await this.$connect();
}
```

### 2. 启动时预热缓存

```typescript
async onApplicationBootstrap() {
  // 所有模块初始化完成后，将常用数据加载到 Redis
  const hotBooks = await this.bookService.findHotBooks();
  await this.redis.set('hot_books', JSON.stringify(hotBooks), 'EX', 600);
}
```

### 3. 关闭前等待请求处理完毕

```typescript
async beforeApplicationShutdown(signal: string) {
  console.log(`收到 ${signal} 信号，等待当前请求完成...`);
  await new Promise(resolve => setTimeout(resolve, 5000));  // 等待 5 秒
}
```

### 4. 关闭时清理资源

```typescript
async onApplicationShutdown() {
  await this.redis.quit();
  await this.prisma.$disconnect();
}
```
