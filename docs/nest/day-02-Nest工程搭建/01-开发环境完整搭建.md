# 开发环境完整搭建

## Node.js 版本管理

推荐使用 nvm（Node Version Manager）管理 Node.js 版本，不同项目可能需要不同版本。

### Windows（nvm-windows）

从 [nvm-windows Releases](https://github.com/coreybutler/nvm-windows/releases) 下载 `nvm-setup.exe` 安装。

```powershell
# 安装 Node.js LTS 版本（推荐 20.x 或 22.x）
nvm install 22.14.0
nvm use 22.14.0

# 验证
node -v   # v22.14.0
npm -v    # 10.x
```

### macOS / Linux

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 重启终端后
nvm install 22
nvm use 22
```

### npm / yarn / pnpm 选哪个？

| 工具 | 优点 | 缺点 | 推荐场景 |
|------|------|------|---------|
| npm | Node.js 自带，零安装 | 安装速度较慢 | 个人项目、不想多装工具 |
| yarn | 确定性依赖（lockfile 诞生地） | 需要额外安装 | 团队项目（v1 经典稳定） |
| pnpm | 磁盘效率高（硬链接）、严格依赖隔离 | 某些老旧包可能不兼容 | 新项目首选、Monorepo |

本教程使用 **pnpm**（更快、更省空间），但 npm/yarn 完全可用——所有命令都有对应版本：

```bash
# 三者的命令对照
npm install          yarn add           pnpm add
npm install -D       yarn add -D        pnpm add -D
npm run dev          yarn dev           pnpm dev
npx nest new ...     yarn nest new ...  pnpm nest new ...
```

## TypeScript 环境

NestJS 项目创建时会自动配置 TypeScript，但全局安装 `ts-node` 有助于日常脚本调试：

```bash
npm install -g typescript ts-node
tsc --version    # Version 5.x
```

### tsconfig.json 关键配置速查

Nest 生成的 `tsconfig.json` 中这些配置值得了解：

```json
{
  "compilerOptions": {
    "target": "ES2021",                // 编译到 ES2021
    "module": "commonjs",              // Node.js 用 commonjs
    "outDir": "./dist",                // 编译输出目录
    "rootDir": "./src",                // 源码根目录
    "strict": true,                    // 严格模式（推荐保持）
    "esModuleInterop": true,           // 兼容 ESM 和 CommonJS
    "experimentalDecorators": true,    // 装饰器支持（Nest 核心依赖）
    "emitDecoratorMetadata": true,     // 装饰器元数据（DI 依赖）
    "skipLibCheck": true               // 跳过 .d.ts 检查（加速编译）
  }
}
```

> `experimentalDecorators` 和 `emitDecoratorMetadata` 是 Nest 的两个核心依赖，**必须开启**。装饰器是 Nest 表达架构意图的核心语法，元数据发射是 IoC 容器自动解析依赖的基础。

## MySQL 8.0 安装与配置

### Windows

1. 下载 [MySQL Community Server](https://dev.mysql.com/downloads/mysql/) MSI Installer
2. 安装时选择 "Developer Default"
3. 设置 root 密码（记住它！教程用 `password`，生产环境用强密码）
4. 确保 MySQL 服务已启动（Windows 服务或任务管理器查看）

### macOS

```bash
brew install mysql@8.0
brew services start mysql@8.0

# 设置 root 密码
mysql_secure_installation
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install mysql-server-8.0
sudo systemctl start mysql
sudo mysql_secure_installation
```

### 验证安装

```bash
mysql -u root -p
# 输入密码后进入 MySQL Shell

CREATE DATABASE test_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
SHOW DATABASES;
DROP DATABASE test_db;
exit;
```

## PostgreSQL 16 安装与配置

### Windows

1. 下载 [PostgreSQL Installer](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads)
2. 安装时设置 postgres 用户密码（记住它！）
3. pgAdmin 会一起安装（图形化管理工具）

### macOS

```bash
brew install postgresql@16
brew services start postgresql@16

# 创建默认用户
createuser -s postgres
```

### Linux (Ubuntu/Debian)

```bash
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql

# 切换到 postgres 用户
sudo -u postgres psql
```

### psql 基本操作

```sql
-- 连接后：创建数据库
CREATE DATABASE test_db;
\c test_db            -- 切换数据库
CREATE TABLE test (id SERIAL PRIMARY KEY, name TEXT);
INSERT INTO test (name) VALUES ('hello');
SELECT * FROM test;
\q                    -- 退出
```

### MySQL vs PostgreSQL 快速对比

| 特性 | MySQL | PostgreSQL |
|------|-------|-----------|
| Schema 概念 | 无（Database=Schema） | 有（Database > Schema > Table） |
| 自增主键 | AUTO_INCREMENT | SERIAL（语法糖） |
| 字符串类型 | VARCHAR, TEXT | VARCHAR, TEXT |
| JSON 支持 | JSON (5.7+) | JSON/JSONB（更快） |
| 大小写 | 默认不区分表名 | 默认区分表名和字段名 |
| 适合场景 | Web 应用、读多写少 | 复杂查询、GIS、分析 |
| 默认端口 | 3306 | 5432 |

> 我们教程以 MySQL 为主要示例，但 Prisma Schema 语法与数据库无关——你只需改 `provider` 和 `@db.*` 即可切换 PostgreSQL。

## 数据库客户端工具推荐

| 工具 | 平台 | 价格 | 特点 |
|------|------|------|------|
| MySQL Workbench | Win/Mac/Linux | 免费 | MySQL 官方、简单直观 |

## 代码编辑器

推荐 **VSCode**（免费 + 生态最强）或 **WebStorm**（如果你有 JetBrains 全家桶）。

VSCode 必装插件：
- **Thunder Client**（轻量 API 测试，替代 Postman）
- **Prisma**（`.prisma` 文件语法高亮和格式化）
- **ESLint** + **Prettier**（代码规范）
- **MySQL** / **PostgreSQL**（数据库连接管理）
