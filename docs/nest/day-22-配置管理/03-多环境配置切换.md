# 多环境配置切换

## 环境层次

```
开发环境 (development)  → 本地数据库 / 宽松 Token 有效期 / verbose 日志
测试环境 (testing)      → 测试数据库 / mock 服务
预发布   (staging)      → 生产类配置 / 做上线前验证
生产环境 (production)   → 真实配置 / 严格安全策略
```

## 方案 1：NODE_ENV 自动切换

```bash
# .env.development（开发环境）
DATABASE_URL=mysql://root:dev123@localhost:3306/book_dev
JWT_SECRET=dev-secret-key
JWT_ACCESS_EXPIRES_IN=2h
LOG_LEVEL=debug

# .env.staging（预发布环境）
DATABASE_URL=mysql://user:staging123@staging-db:3306/book_staging
JWT_SECRET=staging-secret-key
JWT_ACCESS_EXPIRES_IN=15m
LOG_LEVEL=info

# .env.production（生产环境）
DATABASE_URL=mysql://user:prod-password@prod-db:3306/book_prod
JWT_SECRET=prod-super-secret-key
JWT_ACCESS_EXPIRES_IN=15m
LOG_LEVEL=warn
```

```typescript
// src/app.module.ts
import { ConfigModule } from '@nestjs/config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      // 后面的 .env 会覆盖前面的同名变量（前面的优先级高）
      envFilePath: [
        `.env.${process.env.NODE_ENV}`,   // .env.development / .env.production
        '.env',                             // 兜底文件
      ],
    }),
  ],
})
export class AppModule {}
```

### 启动命令

```bash
# 开发环境
NODE_ENV=development npm run start:dev

# 生产环境
NODE_ENV=production npm run start:prod

# package.json 脚本
{
  "scripts": {
    "start:dev": "NODE_ENV=development nest start --watch",
    "start:prod": "NODE_ENV=production node dist/main",
    "start:staging": "NODE_ENV=staging node dist/main"
  }
}
```

## 方案 2：环境专用文件夹

```
config/
├── development.ts
├── staging.ts
└── production.ts
```

```typescript
// config/development.ts
export default {
  database: {
    host: 'localhost',
    port: 3306,
    name: 'book_dev',
  },
  jwt: {
    secret: 'dev-secret',
    expiresIn: '2h',
  },
};

// config/production.ts
export default {
  database: {
    host: 'prod-db.internal',
    port: 3306,
    name: 'book_prod',
  },
  jwt: {
    secret: process.env.JWT_SECRET, // 生产密钥从系统环境变量读取
    expiresIn: '15m',
  },
};
```

```typescript
// src/app.module.ts
import configuration from '../config/development';
// 或动态加载
const env = process.env.NODE_ENV || 'development';
const configuration = require(`../config/${env}`).default;

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [() => configuration],
    }),
  ],
})
export class AppModule {}
```

## 环境变量优先级

```
系统环境变量（最高优先级）
    ↗ 覆盖
.env.{NODE_ENV}（环境专用）
    ↗ 覆盖
.env（默认值）
    ↗ 覆盖
代码中 get(key, defaultValue) 的 defaultValue（最低优先级）
```

> **生产环境最佳实践**：敏感信息（数据库密码、JWT 密钥）通过系统环境变量注入，不写入 `.env` 文件。Docker/K8s 部署时由容器编排平台注入。

## 安全提醒

```bash
# .gitignore——确保不会提交敏感配置！
.env
.env.local
.env.*.local

# 只提交示例文件
.env.example  # ✅ 可以提交（不含真实值）
.env.production  # ❌ 绝对不要提交！
```

```bash
# .env.example
# 数据库连接
DATABASE_URL=mysql://user:PASSWORD@host:port/db_name
JWT_SECRET=change-me-to-random-string
JWT_ACCESS_EXPIRES_IN=30m
JWT_REFRESH_EXPIRES_IN=7d
PORT=3000
REDIS_URL=redis://host:port
```
