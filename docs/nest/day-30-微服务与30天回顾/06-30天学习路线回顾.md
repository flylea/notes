## 你能做什么了

- 独立开发一个 REST API 后端，从数据库设计到部署上线
- 设计用户认证和 RBAC 权限体系
- 用 Docker Compose 编排多服务（Nest + MySQL + Redis + MinIO）
- 用 Nginx 做反向代理、负载均衡和灰度发布
- 为团队搭建 Monorepo，抽共享库
- 阅读和理解 NestJS 官方文档
- 看懂大多数 NestJS 开源项目的代码结构

## 进阶学习方向

### 1. 深度方向

```
Prisma 进阶：
  - Prisma Accelerate（连接池 + 全球边缘缓存）
  - Prisma Pulse（实时数据变更订阅）
  - 多租户架构（Multi-Schema / Row-Level Security）

Nest 源码阅读：
  - DI 容器的实现原理
  - @Injectable() 装饰器的底层机制
  - APP_INTERCEPTOR / APP_GUARD 的全局注册机制

TypeScript 深入：
  - 泛型约束和条件类型
  - decorator metadata 的 emit 机制
  - 自己实现一个 mini DI 容器
```

### 2. 广度方向

```
GraphQL：
  - @nestjs/graphql + Apollo Server
  - Code First vs Schema First
  - DataLoader 解决 N+1 查询

MongoDB：
  - @nestjs/mongoose
  - Mongoose Schema 设计
  - 聚合管道（Aggregation Pipeline）

微服务实战：
  - Kubernetes（K8s）基础
  - 服务发现（Consul / Etcd）
  - 链路追踪（Jaeger / OpenTelemetry）
  - API Gateway（Kong / APISIX）
```

### 3. DevOps 方向

```
CI/CD：
  - GitHub Actions 自动构建 + 推送镜像
  - Docker Registry（私有镜像仓库）
  - 蓝绿部署 / 滚动更新

监控与告警：
  - Prometheus + Grafana 指标监控
  - Sentry 错误追踪
  - 日志收集（ELK / Loki）

云平台：
  - 阿里云 / AWS / Azure 部署实战
  - 云函数（Serverless）
  - CDN + 全站 HTTPS
```

## 推荐的下一步

```
如果你想找份后端工作：
  → 挑一个方向深挖源码 + 做开源贡献
  → 把图书管理系统做完整（前端用 Vue/React），放 GitHub 当作品

如果你是全栈独立开发者：
  → 用这套技术栈接外包或做 SaaS 产品
  → 用 Docker 一键部署到云服务器

如果你是前端 leader：
  → 在团队推行 BFF（Backend For Frontend）模式
  → Nest 写 BFF 层，对前端团队极其友好
```

## 核心学习经验

```
1. 不要追求"全记住"
   你不需要记住 Nest 所有 API，而是在脑子里建索引：
   "我知道 Nest 能做这件事，具体语法去官方文档查"

2. 实战 > 阅读
   看 100 篇教程不如自己写 1 个项目
   修改、改坏、debug、修好——这才是真学会

3. 类比是桥梁
   用前端经验理解后端概念（Module = 组件、DI = provide/inject）
   类比帮你快速建立心智模型，但深入后要跳出类比

4. 官方文档是最好的老师
   NestJS 官方文档质量极高（可能是 Node 生态最好的）
   遇到问题，优先查官方文档，其次是 GitHub Issues
```
