# Day 14：数据库基础与 Prisma 入门

## 今日概览

Day 6-12 我们一直用 JSON 文件存储数据。从今天起，正式进入数据库世界。我们将学习 MySQL 和 PostgreSQL 的核心概念，然后在两者之间选择合适的工具。

## 学习目标

- 回顾 MySQL 和 PostgreSQL 的核心概念和差异
- 掌握 SQL CRUD 基本语法
- 理解表关系设计（一对一/一对多/多对多）
- 理解 ORM 概念和 Prisma vs TypeORM 的差异
- 完成 Prisma 的初始化和首次迁移
