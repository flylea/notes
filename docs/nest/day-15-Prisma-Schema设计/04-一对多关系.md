# 一对多关系

## 基本结构

```prisma
model User {
  id    BigInt  @id @default(autoincrement())
  books Book[]  // ← "一" 方：一个 User 有多个 Book
}

model Book {
  id     BigInt @id @default(autoincrement())
  user   User   @relation(fields: [userId], references: [id])  // ← "多" 方
  userId BigInt // 外键字段
}
```

## @relation 详解

```prisma
model Book {
  user   User @relation(
    fields: [userId],    // 当前 model 中的外键字段
    references: [id],    // 关联到 User 的哪个字段
    onDelete: Cascade,   // 删除 User 时级联删除 Book
    onUpdate: Cascade,   // User.id 更新时级联更新（极少用）
    name: "UserBooks"    // 关系名：同一对 model 有多条关系时必填
  )
  userId BigInt
}
```

## onDelete 选项

| 选项 | 行为 |
|------|------|
| `Cascade` | 删除父记录 → 同时删除所有子记录 |
| `Restrict` | 有子记录存在 → 禁止删除父记录 |
| `NoAction` | 同 Restrict（MySQL 默认） |
| `SetNull` | 删除父记录 → 子记录的外键设为 NULL（外键必须可选） |
| `SetDefault` | 删除父记录 → 外键设为默认值 |

## 双向关联的可选性

```prisma
// 只需要单向查询时，可以省略反向关系
model BorrowRecord {
  user   User   @relation(fields: [userId], references: [id])
  userId BigInt
  // User 那边不需要有 borrows BorrowRecord[]（除非需要从 User 查其借阅记录）
}
```

## 图书管理系统示例

```prisma
model User {
  id       BigInt          @id @default(autoincrement())
  username String          @unique
  borrows  BorrowRecord[]  // 一对多：用户有多条借阅记录
}

model BorrowRecord {
  id         BigInt   @id @default(autoincrement())
  user       User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  userId     BigInt
  book       Book     @relation(fields: [bookId], references: [id], onDelete: Cascade)
  bookId     BigInt
  borrowedAt DateTime @default(now())
  returnedAt DateTime?
}
```

> 一对多是数据库中最常见的关系——它是所有关联查询的基础。
