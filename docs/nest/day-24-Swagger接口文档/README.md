# Day 24：Swagger API 文档

## 今日概览

后端接口没有文档，前端同事不知道调哪个 URL、传什么参数。今天用 @nestjs/swagger 为图书管理系统生成在线 API 文档，并支持在线调试。

## 学习目标

- 理解 Swagger/OpenAPI 的作用
- 配置 DocumentBuilder 构建文档
- 掌握全部 Swagger 装饰器
- 为 DTO 添加 @ApiProperty 标注
- 为图书管理系统生成完整文档
