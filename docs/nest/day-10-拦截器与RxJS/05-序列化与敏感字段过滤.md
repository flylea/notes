# ClassSerializerInterceptor — 过滤敏感字段

## 问题：password 字段泄露

```typescript
// user.entity.ts
export class User {
  id: string;
  username: string;
  password: string;  // ← 绝不能在响应中返回!
}

// user.service.ts
findOne(id: string): User {
  return { id: '1', username: 'john', password: '123456' };
}

// 响应：{ id: '1', username: 'john', password: '123456' }
// ← password 被返回了！
```

手动过滤：

```typescript
// 每个返回方法都要记得排除 password
const { password, ...safeUser } = user;
return safeUser;
```

这很脆弱——新来的同事忘了排除，就直接泄露。

## 解决方案：ClassSerializerInterceptor

```typescript
import { Exclude, Expose, Transform } from 'class-transformer';

export class UserEntity {
  id: string;

  username: string;

  @Exclude()  // ← 序列化时排除此字段
  password: string;

  @Expose()   // 显式暴露
  get displayName(): string {
    return `${this.username} (${this.id})`;
  }
}
```

Controller 中使用：

```typescript
@Controller('user')
@UseInterceptors(ClassSerializerInterceptor)  // 启用序列化过滤
export class UserController {
  @Get(':id')
  findOne(@Param('id') id: string) {
    return this.userService.findOne(id);
    // 返回的 UserEntity 中 @Exclude() 字段会被自动移除
  }
}
```

响应：
```json
{
  "id": "1",
  "username": "john",
  "displayName": "john (1)"
}
// password 被移除了
```

## ClassSerializerInterceptor 工作原理

```
Controller 返回 UserEntity 实例
  ↓
ClassSerializerInterceptor
  ↓ 调用 instanceToPlain(instance)
  ↓ 执行规则：
  ↓   - @Exclude() 的属性 → 从结果中删除
  ↓   - @Expose() 的属性 → 强制包含
  ↓   - @Transform() → 执行自定义转换
  ↓
返回普通 JS 对象（无 password）
  ↓
Nest 自动 JSON.stringify() → HTTP 响应
```

> ⚠️ `ClassSerializerInterceptor` 需要 `class-transformer` 包（已在 class-validator 安装时一并安装）。它只对**类的实例**生效，如果是普通对象 `{ username: 'john' }`，不会生效。

## 核心装饰器速查

| 装饰器 | 作用 |
|--------|------|
| `@Exclude()` | 序列化时排除该字段 |
| `@Expose()` | 显式暴露（默认所有字段都暴露，但有了 `@Exclude()` 后需要它来"解禁"） |
| `@Expose({ groups: ['admin'] })` | 仅特定分组可见 |
| `@Transform(fn)` | 自定义转换 |
| `@SerializeOptions({ excludePrefixes: ['_'] })` | 排除以下划线开头的字段 |

## 实例：图书管理系统 UserEntity

```typescript
import { Exclude, Expose, Transform } from 'class-transformer';
import { randomUUID } from 'crypto';

export class UserEntity {
  id: string = randomUUID();

  username: string;

  @Exclude()  // 永远不在响应中返回密码
  password: string;

  @Exclude()
  refreshToken?: string;  // JWT refresh token → 也不能返回

  // 虚拟字段：计算属性
  @Expose()
  get avatarUrl(): string {
    return `/avatars/${this.id}.jpg`;
  }

  // 字段别名
  @Expose({ name: 'createdAt' })
  @Transform(({ value }) => value?.toISOString?.() ?? value)
  registerDate: Date;

  // 分组暴露
  @Expose({ groups: ['admin'] })
  role: string = 'user';

  // 条件转换
  @Transform(({ value }) => value ? '***' : undefined)
  phone?: string;

  constructor(partial: Partial<UserEntity>) {
    Object.assign(this, partial);
  }
}
```

## 全局启用

```typescript
// main.ts
import { ClassSerializerInterceptor } from '@nestjs/common';

app.useGlobalInterceptors(new ClassSerializerInterceptor(app.get(Reflector)));
// 注意：需要传入 Reflector 实例，因为 ClassSerializerInterceptor 内部依赖它
```

## @SerializeOptions 控制序列化行为

```typescript
// Controller 级别配置
@Controller('user')
@SerializeOptions({
  excludePrefixes: ['_'],  // 私有字段排除
  groups: ['user'],        // 只输出 user 分组
  excludeExtraneousValues: false,  // @Expose() 显式声明才暴露（严格模式）
})
@UseInterceptors(ClassSerializerInterceptor)
export class UserController {}
```

## 小结

| 需求 | 方案 |
|------|------|
| 密码、token 不返回 | `@Exclude()` |
| 计算属性需要返回 | `@Expose()` + getter |
| 只返回部分字段 | `@Expose()` 单独声明 |
| 字段需要重命名 | `@Expose({ name: 'newName' })` |
| 字段值需要转换 | `@Transform(fn)` |
| 不同角色看到不同字段 | `groups: ['admin', 'user']` |

> `ClassSerializerInterceptor` 是防御性编程的核心工具——即使 Service 层忘了处理 password，它也能在最后一道防线挡住。
