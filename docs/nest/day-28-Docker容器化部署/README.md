# Day 28：Docker 部署

## 今日概览

本地开发完成，要把整个项目搬上服务器。Docker 让部署变得可复制：一次构建，到处运行。今天学习 Nest 项目的容器化部署。

## 学习目标

- 理解 Docker 核心概念（Image/Container/Volume/Network）
- 编写 Nest 项目的 Dockerfile
- 使用多阶段构建优化镜像体积
- 用 Docker Compose 编排多服务（Nest + MySQL/PG + Redis + MinIO）
