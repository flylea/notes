# 嵌套写入

## 什么是嵌套写入？

在创建/更新记录时，同时处理关联数据——一条 API 调用完成主表和关联表的操作。

## create — 创建时连带关联

```typescript
// 创建图书并同时创建借阅记录
const book = await prisma.book.create({
  data: {
    title: 'Nest 实战',
    author: '张三',
    borrows: {
      create: {
        user: { connect: { id: 1 } },  // 关联已有用户
        borrowedAt: new Date(),
      },
    },
  },
});
```

## connect — 关联已有记录

```typescript
// 给已有图书添加标签
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      connect: [{ id: 1 }, { id: 2 }],  // 关联已有标签（通过 ID）
    },
  },
});

// 通过唯一字段关联
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      connect: { name: 'NestJS' },  // 通过 unique 字段
    },
  },
});
```

## disconnect / set — 解除关联

```typescript
// disconnect：解除特定关联
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      disconnect: [{ id: 1 }],  // 只解除 id=1 的标签
    },
  },
});

// set：替换全部关联（先全部断开，再建立新关联）
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      set: [{ id: 3 }],  // 只保留 id=3 的标签
    },
  },
});
```

## create / connectOrCreate — 创建关联

```typescript
// 创建新关联
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      create: { name: 'TypeScript' },  // 创建新标签并关联
    },
  },
});

// connectOrCreate：有则关联，没有就创建
await prisma.book.update({
  where: { id: 1 },
  data: {
    tags: {
      connectOrCreate: {
        where: { name: 'NestJS' },
        create: { name: 'NestJS' },
      },
    },
  },
});
```

## 嵌套操作速查表

| 操作 | 作用 |
|------|------|
| `create` | 创建新记录并关联 |
| `connect` | 关联已有记录 |
| `disconnect` | 解除关联 |
| `set` | 替换全部关联 |
| `delete` | 删除关联的记录 |
| `update` | 更新关联的记录 |
| `upsert` | 有则更新、无则创建 |
| `connectOrCreate` | 有则关联、无则创建 |
