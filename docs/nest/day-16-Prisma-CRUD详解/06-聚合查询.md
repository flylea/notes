# 聚合查询

## aggregate — 统计函数

```typescript
const result = await prisma.book.aggregate({
  _count: { id: true },     // 计数
  _sum: { price: true },    // 求和
  _avg: { price: true },    // 平均值
  _min: { price: true },    // 最小值
  _max: { price: true },    // 最大值
});

console.log(result._sum.price);   // 所有书的价格总和
console.log(result._avg.price);   // 平均价格
console.log(result._count.id);    // 图书总数
```

## groupBy — 分组统计

```typescript
// 按状态分组统计
const result = await prisma.book.groupBy({
  by: ['status'],
  _count: { id: true },
  _sum: { price: true },
  where: { price: { gt: 0 } },
  having: {
    id: { _count: { gt: 5 } },  // 只返回数量 > 5 的分组
  },
  orderBy: { _count: { id: 'desc' } },
});

// 结果：
// [
//   { status: 'available', _count: { id: 150 }, _sum: { price: 12000 } },
//   { status: 'borrowed', _count: { id: 23 }, _sum: { price: 1800 } },
// ]
```

## 聚合函数列表

| 函数 | 可用于 | 示例 |
|------|--------|------|
| `_count` | 任何字段 | 记录数 |
| `_sum` | Int, Float, Decimal | 总金额 |
| `_avg` | Int, Float, Decimal | 平均分 |
| `_min` | 数值、字符串、日期 | 最低价格 |
| `_max` | 数值、字符串、日期 | 最高价格 |

## 图书管理系统常见查询

```typescript
// 各分类图书数量
const categoryStats = await prisma.book.groupBy({
  by: ['status'],
  _count: { id: true },
});

// 最贵的 5 本书
const topExpensive = await prisma.book.findMany({
  orderBy: { price: 'desc' },
  take: 5,
  where: { price: { not: null } },
});

// 各作者写了几本书
const authorStats = await prisma.book.groupBy({
  by: ['author'],
  _count: { id: true },
  orderBy: { _count: { id: 'desc' } },
  take: 10,
});
```

> 聚合查询适合做仪表盘和统计报表。复杂多表联查建议用 `$queryRaw` 写原生 SQL。
