# 自定义业务异常类

## 为什么需要自定义异常？

内置异常只有 HTTP 状态码和消息。但实际业务需要携带更多信息：错误码、错误字段、是否可重试等。

```json
// 内置异常的响应
{ "statusCode": 400, "message": "该用户已注册", "error": "Bad Request" }

// 自定义异常的响应——更丰富的业务信息
{
  "code": 10001,
  "message": "该用户已注册",
  "field": "username",
  "retryable": false
}
```

## 基础：继承 HttpException

```typescript
import { HttpException, HttpStatus } from '@nestjs/common';

export class BusinessException extends HttpException {
  constructor(
    message: string,
    code: number = -1,
    status: HttpStatus = HttpStatus.BAD_REQUEST,
  ) {
    super(
      {
        code,
        message,
        data: null,
        timestamp: new Date().toISOString(),
      },
      status,
    );
  }
}

// 使用
throw new BusinessException('该用户已注册', 10001);
throw new BusinessException('余额不足', 20001, HttpStatus.PAYMENT_REQUIRED);
```

响应：
```json
{
  "code": 10001,
  "message": "该用户已注册",
  "data": null,
  "timestamp": "2026-05-10T14:30:00.000Z"
}
```

## 按业务域分类异常

```typescript
// src/common/exceptions/user.exception.ts
import { HttpException, HttpStatus } from '@nestjs/common';

export class UserNotFoundException extends HttpException {
  constructor(username?: string) {
    super(
      {
        code: 10001,
        message: username ? `用户 "${username}" 不存在` : '用户不存在',
      },
      HttpStatus.NOT_FOUND,
    );
  }
}

export class UserAlreadyExistsException extends HttpException {
  constructor(username: string) {
    super(
      {
        code: 10002,
        message: `用户 "${username}" 已注册`,
        field: 'username',
      },
      HttpStatus.CONFLICT,  // 409
    );
  }
}

export class InvalidPasswordException extends HttpException {
  constructor() {
    super(
      {
        code: 10003,
        message: '密码不正确',
        field: 'password',
      },
      HttpStatus.BAD_REQUEST,
    );
  }
}
```

### 使用

```typescript
// user.service.ts
async login(dto: LoginUserDto) {
  const user = await this.prisma.user.findUnique({
    where: { username: dto.username },
  });

  if (!user) {
    throw new UserNotFoundException(dto.username);
    // → 404 { code: 10001, message: '用户 "john" 不存在' }
  }

  if (user.password !== hashPassword(dto.password)) {
    throw new InvalidPasswordException();
    // → 400 { code: 10003, message: '密码不正确', field: 'password' }
  }

  return { token: issueToken(user) };
}
```

## 错误码规范

| 范围 | 含义 | 示例 |
|------|------|------|
| 10000-19999 | 用户模块错误 | 10001 用户不存在，10002 已注册 |
| 20000-29999 | 图书模块错误 | 20001 图书不存在，20002 已借出 |
| 30000-39999 | 借阅模块错误 | 30001 已达借阅上限，30002 逾期未还 |
| 90000-99999 | 系统级错误 | 90001 数据库错误，90002 网络超时 |

```typescript
// src/common/constants/error-codes.ts
export enum ErrorCode {
  // 用户模块
  USER_NOT_FOUND = 10001,
  USER_ALREADY_EXISTS = 10002,
  INVALID_PASSWORD = 10003,
  USERNAME_EMPTY = 10004,

  // 图书模块
  BOOK_NOT_FOUND = 20001,
  BOOK_ALREADY_BORROWED = 20002,

  // 借阅模块
  BORROW_LIMIT_EXCEEDED = 30001,
  BOOK_NOT_BORROWED = 30002,

  // 通用
  VALIDATION_FAILED = 90000,
  DATABASE_ERROR = 90001,
}
```

## 继承链路设计

```
HttpException  (Nest 内置)
  ├── BusinessException  (项目基类：统一响应格式)
  │   ├── UserException
  │   │   ├── UserNotFoundException
  │   │   ├── UserAlreadyExistsException
  │   │   └── InvalidPasswordException
  │   ├── BookException
  │   │   ├── BookNotFoundException
  │   │   └── BookAlreadyBorrowedException
  │   └── SystemException
  │       └── DatabaseException
  └── (Nest 内置异常：BadRequestException 等，仍可直接使用)
```

```typescript
// src/common/exceptions/base.exception.ts
export class BusinessException extends HttpException {
  readonly code: number;
  readonly field?: string;

  constructor(options: {
    message: string;
    code: number;
    status?: HttpStatus;
    field?: string;
    data?: any;
  }) {
    super(
      {
        code: options.code,
        message: options.message,
        field: options.field,
        data: options.data ?? null,
        timestamp: new Date().toISOString(),
      },
      options.status ?? HttpStatus.BAD_REQUEST,
    );
    this.code = options.code;
    this.field = options.field;
  }
}
```

## @Catch 捕获自定义异常

自定义异常也是 `HttpException` 的子类，所以 `@Catch(HttpException)` 的 Filter 能捕获它们。如果想要特殊处理：

```typescript
@Catch(UserNotFoundException)
export class UserExceptionFilter implements ExceptionFilter {
  catch(exception: UserNotFoundException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();

    response.status(HttpStatus.NOT_FOUND).json({
      ...exception.getResponse(),
      suggestion: '请检查用户名是否正确或前往注册页面',
    });
  }
}
```

> 自定义异常让错误信息从"HTTP 状态码"升级为"业务事件"。前端可以根据 `code` 精确判断错误类型，实现差异化的 UI 提示。
