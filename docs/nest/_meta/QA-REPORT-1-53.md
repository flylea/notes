## 4. 这轮统一做了什么

1. **每章一条主线**：开头用一个具体场景或事故把人拽进来，后面所有小节都为这条线服务，不再是「知识点罗列 + 代码」。
2. **新概念三句话**：它是什么（生活类比）→ 没有它会卡在哪 → 和最容易混的那个差在哪；然后才给术语。
3. **从零解释不删**：后面章节再遇到同一个词，用一句话复述并注明「第几章讲过」，不丢链接了事。
4. **保留全部既有资产**：文件名、一级标题、页脚导航、版本号、正确代码、官方文档链接、Mermaid 图、原有「未实测」标注都没动；没有编造任何命令输出。
