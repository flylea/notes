## 三、单节质量标准（比门禁更严，写作时按这个来）

- **汉字 2,800–3,500**（门禁只要求 ≥800，但低质量会拉低整本书密度；当前 63 节均值 3,033）。
- **代码块 8–16 个**，全部可复制；shell 命令必须给预期输出或失败现象。
- 版本一律写真实值：Nest 12.6.x、Node 22/24/26 LTS、TS 6.0.x、Prisma 8 `rc.34` + `@prisma/orm-postgres` `rc.24`、`@nestjs/jwt` 12.0.x、`express-session` 1.19、`connect-redis` 11（peer 是 node-redis，用 ioredis 自写 store 时要说明）。
- ESM 口径：相对导入带 `.js`、`main.ts` 顶层 `await`、`package.json` `"type": "module"`。
- Prisma 8 口径：`contract.prisma` 首行 `// use prisma-8`、`prisma contract emit`、`postgres({ contract, url })`、`db.orm.public.X`、`db.transaction`。
- 每节至少 1 个 **checkpoint**（可粘贴命令 + 期望输出），让读者能停下来验证。
- 禁止教材腔（`本章目标`/`前置知识`/`小结`/`延伸阅读`/`学完你将`…），已写在 `_meta/validate-chapters.mjs` 的 FORBIDDEN。
- 图：`架构/原理/流程/协议/时序/关系/部署/生命周期/数据流/可靠性/可观测` 这些 domain 必须有 Mermaid；其他节有更好。
- **未实测内容显式标注**：「以下为预期输出，未在本机实测」——新增节平均每节不超过 3 处，且 Docker/云相关必须标。
- 不写测试章、正文不展示 Vitest/Jest/k6（用户决定，见 `WRITER-BRIEF.md`「测试口径」）。
- H1 固定为 `# NN.MM 节标题`；页脚由脚本生成，不要手写。
