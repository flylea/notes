# 按日期轮转日志文件

## 为什么需要轮转

```
没有轮转：
  app.log — 运行 3 个月 → 500MB
  打开 → 编辑器卡死
  grep → 极慢
  磁盘 → 占满

有轮转：
  logs/
  ├── app-2024-01-15.log    (15MB)
  ├── app-2024-01-14.log    (14MB)
  ├── app-2024-01-13.log    (16MB)
  └── ...
  每天一个文件，自动清理旧文件
```

## 安装

```bash
npm install winston-daily-rotate-file
```

## 配置

```typescript
import 'winston-daily-rotate-file';
import { transports } from 'winston';

const dailyRotateTransport = new transports.DailyRotateFile({
  // 文件命名模式
  filename: 'logs/app-%DATE%.log',
  datePattern: 'YYYY-MM-DD',

  // 单个文件最大大小（超过后当天也会切分）
  maxSize: '20m',

  // 最多保留多少天的日志
  maxFiles: '14d',

  // 是否压缩旧日志（gzip）
  zippedArchive: true,

  // 日志级别过滤
  level: 'info',

  // 格式
  format: format.combine(
    format.timestamp(),
    format.json(),
  ),
});
```

## 完整的生产级配置

```typescript
// src/common/logger.config.ts
import { transports, format } from 'winston';
import 'winston-daily-rotate-file';

const isProduction = process.env.NODE_ENV === 'production';

export function createWinstonTransports() {
  const transportList: any[] = [
    // 控制台——所有环境
    new transports.Console({
      format: format.combine(
        format.colorize(),
        format.timestamp({ format: 'HH:mm:ss.SSS' }),
        format.printf(({ timestamp, level, message, context, ...meta }) => {
          const ctx = context ? `[${context}] ` : '';
          const metaStr = Object.keys(meta).length ? ` ${JSON.stringify(meta)}` : '';
          return `${timestamp} ${level} ${ctx}${message}${metaStr}`;
        }),
      ),
    }),
  ];

  // 生产环境——文件轮转
  if (isProduction) {
    transportList.push(
      // 所有日志——按日轮转
      new transports.DailyRotateFile({
        filename: 'logs/app-%DATE%.log',
        datePattern: 'YYYY-MM-DD',
        maxSize: '20m',
        maxFiles: '30d',
        zippedArchive: true,
        format: format.combine(format.timestamp(), format.json()),
      }),
      // 错误日志——单独存储
      new transports.DailyRotateFile({
        filename: 'logs/error-%DATE%.log',
        datePattern: 'YYYY-MM-DD',
        level: 'error',
        maxSize: '20m',
        maxFiles: '90d',
        format: format.combine(format.timestamp(), format.json()),
      }),
      // 慢查询日志——性能监控
      new transports.DailyRotateFile({
        filename: 'logs/slow-query-%DATE%.log',
        datePattern: 'YYYY-MM-DD',
        level: 'warn',
        maxFiles: '30d',
        format: format.combine(format.timestamp(), format.json()),
      }),
    );
  }

  return transportList;
}
```

## 日志目录结构

```
logs/
├── app-2024-01-15.log          ← 今天的所有日志
├── app-2024-01-14.log.gz       ← 昨天的（已压缩）
├── app-2024-01-13.log.gz       ← 前天的（已压缩）
├── error-2024-01-15.log        ← 今天的错误日志
├── error-2024-01-14.log.gz     ← 昨天的错误日志
└── slow-query-2024-01-15.log   ← 慢查询日志
```

## 清理策略

```typescript
// maxFiles 的含义
maxFiles: '14d'   → 保留 14 天内的日志，超出的自动删除
maxFiles: 30      → 保留 30 个文件，超出的自动删除
maxFiles: '3d'    → 开发环境只保留 3 天

// 结合 maxSize
maxSize: '20m'    → 单个文件超过 20MB 时，当天也会切分
// 生成：app-2024-01-15.1.log, app-2024-01-15.2.log, ...
```

## 生产日志最佳实践

```
1. 日志分级存储
   error 级别 → 单独文件，保留 90 天
   普通日志 → 保留 30 天
   调试日志 → 开发环境，不写文件

2. 日志压缩
   7 天前的日志自动 gzip——节省 80-90% 磁盘

3. 敏感信息脱敏
   password、token 等字段自动替换为 ***
```

```typescript
// 敏感信息脱敏 Format
const maskSensitive = format((info) => {
  if (info.password) info.password = '***';
  if (info.token) info.token = info.token.slice(0, 10) + '...';
  if (info.authorization) info.authorization = '***';
  return info;
});

const logger = createLogger({
  format: format.combine(
    maskSensitive(),
    format.timestamp(),
    format.json(),
  ),
});
```
